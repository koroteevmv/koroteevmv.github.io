### Производная: геометрический и физический смысл (DS)

В машинном обучении нам постоянно нужно отвечать на вопрос: «Как изменится ошибка модели, если мы чуть-чуть подкрутим параметр?» Или: «В каком направлении нужно двигаться, чтобы быстрее всего спуститься в минимум функции потерь?» Ответ даёт **производная** — одно из самых фундаментальных понятий математического анализа. Понимание производной на интуитивном уровне (геометрическом и физическом) — ключ к освоению градиентного спуска и обратного распространения ошибки.

#### Геометрический смысл: наклон касательной

Представьте себе график функции $y = f(x)$ на плоскости. Выберите на нём точку $A(x_0, f(x_0))$. Если вы немного сдвинетесь по графику в соседнюю точку $B(x_0 + h, f(x_0 + h))$, то через $A$ и $B$ можно провести прямую — **секущую**. Её наклон (угловой коэффициент) равен отношению вертикального изменения к горизонтальному:

$$ \frac{f(x_0 + h) - f(x_0)}{h}. $$

Когда $h$ становится очень маленьким (стремится к нулю), секущая «прижимается» к графику и превращается в **касательную** в точке $A$. Предел этого отношения и есть производная:

{% capture notice %}
**Определение производной.** Производной функции $f$ в точке $x_0$ называется предел

$$ f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}, $$

если этот предел существует (и конечен).
{% endcapture %}

Геометрически $f'(x_0)$ — это угловой коэффициент касательной к графику $f$ в точке $(x_0, f(x_0))$. Иными словами, касательная задаётся уравнением $y = f(x_0) + f'(x_0)(x - x_0)$. Если производная положительна, функция в этой точке возрастает (касательная «смотрит вверх»); если отрицательна — убывает; если равна нулю — касательная горизонтальна, что может указывать на экстремум.

[АНИМАЦИЯ: На графике функции $y=x^2$ движется точка $A$. Секущая через $A$ и соседнюю точку $B$ постепенно приближается к касательной по мере уменьшения $h$. Подпись: «Чем меньше $h$, тем ближе секущая к касательной».]

[КАРТИНКА: График $y = x^3 - 3x$ с отмеченными касательными в точках $x = -1$ (горизонтальная), $x = 0$ (отрицательный наклон), $x = 1$ (горизонтальная), $x = 1.5$ (положительный наклон).]

#### Физический смысл: мгновенная скорость

Если интерпретировать $f(t)$ как путь, пройденный объектом за время $t$, то средняя скорость на отрезке $[t_0, t_0 + h]$ равна $\frac{f(t_0 + h) - f(t_0)}{h}$. Производная $f'(t_0)$ — это **мгновенная скорость** в момент $t_0$. Именно её показывает спидометр автомобиля. В машинном обучении аналогия: параметр модели «движется» во времени (итерации градиентного спуска), а производная функции потерь по параметру говорит, насколько быстро и в какую сторону меняется ошибка.

[АНИМАЦИЯ: Движущаяся точка на числовой прямой; рядом график пути от времени, касательная в текущий момент показывает мгновенную скорость. Подпись: «Производная пути по времени — мгновенная скорость».]

#### Вычисление производной: от определения к правилам

Пользуясь определением, можно вычислить производную для простых функций. Например, для $f(x) = x^2$:

$$ f'(x_0) = \lim_{h \to 0} \frac{(x_0 + h)^2 - x_0^2}{h} = \lim_{h \to 0} \frac{2x_0 h + h^2}{h} = \lim_{h \to 0} (2x_0 + h) = 2x_0$$

Физический смысл: если $x$ — время, а $x^2$ — пройденный путь, то мгновенная скорость растёт линейно: $2x$.

Но в реальных задачах ML (а особенно при обратном распространении ошибки) нам нужны производные сложных композиций. Для этого существуют правила дифференцирования: производная суммы, произведения, частного, а самое главное — **цепное правило**:

$$ (f(g(x)))' = f'(g(x)) \cdot g'(x). $$

Именно цепное правило позволяет «протаскивать» градиент через слои нейросети.

#### Численная реализация производной «своими руками»

Прежде чем пользоваться автоматическим дифференцированием в PyTorch или TensorFlow, полезно понять, как можно приближённо вычислить производную на компьютере — ведь компьютер работает с дискретными числами, а не с бесконечно малыми $h$.

Простейший способ — **конечная разность**:

$$ f'(x) \approx \frac{f(x + h) - f(x)}{h} $$

для маленького $h$, например $10^{-7}$. Однако более точна **центральная разность** (ошибка порядка $h^2$ вместо $h$):

$$ f'(x) \approx \frac{f(x + h) - f(x - h)}{2h}. $$

Реализуем это в коде для $f(x) = \sin(x)$ и сравним с аналитической производной $\cos(x)$.

```python
import math

def numerical_derivative(f, x, h=1e-7):
    """Центральная разность для приближённой производной."""
    return (f(x + h) - f(x - h)) / (2 * h)

def f_sin(x):
    return math.sin(x)

def f_sin_deriv_analytic(x):
    return math.cos(x)

x0 = 1.0
num = numerical_derivative(f_sin, x0)
ana = f_sin_deriv_analytic(x0)
print(f"x = {x0}")
print(f"Численная производная sin: {num:.10f}")
print(f"Аналитическая производная cos: {ana:.10f}")
```

Вывод (примерный):

```
x = 1.0
Численная производная sin: 0.5403023059
Аналитическая производная cos: 0.5403023059
```

Значения совпадают до 10 знаков после запятой — отлично.

Теперь напишем функцию, которая одновременно вычисляет значение функции и её производную (потребуется для градиентного спуска на одномерных задачах).

```python
def value_and_derivative(f, x, h=1e-7):
    """Возвращает (f(x), f'(x)) с помощью центральной разности."""
    fx = f(x)
    deriv = (f(x + h) - f(x - h)) / (2 * h)
    return fx, deriv

# Пример: f(x) = x^3 - 2x
def cubic(x):
    return x**3 - 2*x

x_test = 2.0
val, grad = value_and_derivative(cubic, x_test)
print(f"f({x_test}) = {val}, f'({x_test}) ≈ {grad}")
# Аналитически: 3x^2 - 2 -> при x=2: 12-2=10
```

Вывод:

```
f(2.0) = 4.0, f'(2.0) ≈ 10.0000000001
```

#### От производной к градиентному спуску

В машинном обучении мы часто хотим найти минимум функции потерь $L(w)$, где $w$ — скалярный параметр. Если $L$ дифференцируема, то в точке минимума $L'(w) = 0$. Правило обновления градиентного спуска:

$$ w_{\text{новое}} = w_{\text{старое}} - \eta \, L'(w_{\text{старое}}), $$

где $\eta$ — скорость обучения (шаг). Геометрический смысл: если производная положительна, функция растёт, значит, нужно двигаться влево ($w$ уменьшать). Если производная отрицательна — вправо ($w$ увеличивать). Множитель $\eta$ контролирует длину шага.

[АНИМАЦИЯ: На графике квадратичной параболы $L(w)=w^2$ показана траектория градиентного спуска: из начальной точки $w_0$ спуск к $w=0$ с шагами, пропорциональными производной. Подпись: «Направление движения — против знака производной».]

Реализуем простейший градиентный спуск для $L(w) = (w-3)^2$ (минимум в $w=3$):

```python
def loss(w):
    return (w - 3)**2

def loss_derivative(w):
    return 2 * (w - 3)

def gradient_descent(deriv_func, w_start, learning_rate, steps):
    w = w_start
    trajectory = [w]
    for _ in range(steps):
        w = w - learning_rate * deriv_func(w)
        trajectory.append(w)
    return trajectory

w0 = 8.0
eta = 0.1
steps = 30
path = gradient_descent(loss_derivative, w0, eta, steps)
print("Начальное w:", w0)
print("w после 30 шагов:", path[-1])
print("Глобальный минимум: 3.0")
```

Вывод:

```
Начальное w: 8.0
w после 30 шагов: 3.0000000012
Глобальный минимум: 3.0
```

Мы видим, что итеративно приближаемся к $w=3$. В реальных моделях функция потерь зависит от многих параметров, и производная превращается в градиент, но принцип остаётся тем же.

#### Пример из ML: логистическая регрессия (одномерный признак)

Пусть у нас есть один признак $x$ и бинарная метка $y \in \{0,1\}$. Модель: $\hat{y} = \sigma(w x + b)$, где $\sigma$ — сигмоида. Функция потерь (логистическая) для одного примера:

$$ L(w,b) = -y \ln(\hat{y}) - (1-y)\ln(1-\hat{y}). $$

Производная $L$ по $w$ имеет вид $(\hat{y} - y)x$. Именно она используется в градиентном спуске. Без понимания производной мы не смогли бы ни вывести эти формулы, ни реализовать обучение.

#### Зачем всё это в анализе данных?

- **Градиентный спуск** — основной алгоритм оптимизации в ML, он полностью опирается на вычисление производных.
- **Настройка гиперпараметров** (например, скорости обучения) опирается на анализ поведения производной.
- **Проверка корректности градиентов** (градиентный тест) использует численное дифференцирование — тот самый метод центральной разности.
- Понимание производной помогает интерпретировать, как изменение входных признаков влияет на предсказание.

#### Основные выводы

- **Производная $f'(x_0)$** геометрически — наклон касательной к графику функции в точке $x_0$. Физически — мгновенная скорость изменения величины.
- Вычисляется как предел разностного отношения; на практике для проверки используют численное дифференцирование (центральную разность).
- В машинном обучении производная (и её многомерное обобщение — градиент) указывает направление наискорейшего роста функции потерь. Двигаясь **против** направления производной, мы уменьшаем ошибку.
- **Цепное правило** — основа обратного распространения ошибки в нейронных сетях.
- Освоив производную простой функции, вы легко перейдёте к градиентам и оптимизации глубоких моделей.

### Производная: геометрический и физический смысл (CO)

Производная — главное понятие математического анализа и, без преувеличения, самый важный математический объект для машинного обучения. Когда мы обучаем нейросеть, мы не делаем ничего другого, кроме как вычисляем производные и используем их для обновления весов. Алгоритм обратного распространения ошибки — это просто продуманная схема вычисления производных. Градиентный спуск — это движение по производным. Все современные фреймворки глубокого обучения построены вокруг автоматического дифференцирования. Поэтому стоит потратить время и понять, что такое производная, очень глубоко — не на уровне формулы, а на уровне интуиции.

Интересно, что у производной, как и у вектора, есть несколько эквивалентных интерпретаций, и каждая из них раскрывает свою грань этого понятия. Самые важные — геометрическая (наклон касательной), физическая (мгновенная скорость) и алгебраическая (коэффициент линейного приближения). Понимание всех трёх и связей между ними даст наиболее полное представление о том, что такое производная.

#### Производная как скорость изменения

Начнём с простой житейской интуиции. Представьте, что вы едете на машине. Каждую секунду одометр показывает, сколько километров вы проехали — это функция $s(t)$, расстояние от времени. А что показывает спидометр? Он показывает, как быстро меняется $s(t)$ прямо сейчас, в текущий момент. Это и есть производная $s'(t)$ — мгновенная скорость.

Можно прикинуть скорость грубо: проехали $100$ метров за $5$ секунд — значит, средняя скорость $20$ м/с. Формально:

$$ \bar v = \frac{s(t + \Delta t) - s(t)}{\Delta t}. $$

Это **средняя скорость** на интервале $[t, t + \Delta t]$. Но средняя скорость — это не то, что показывает спидометр. Спидометр показывает скорость *в один конкретный момент*. Чтобы получить её, нужно сделать интервал $\Delta t$ всё меньше и меньше — в пределе перейти к мгновенной скорости.

[АНИМАЦИЯ: машина движется по дороге, под графиком $s(t)$ нарисован интервал $[t, t + \Delta t]$ и подписано отношение $(s(t+\Delta t) - s(t))/\Delta t$; интервал постепенно сжимается до нуля, и значение отношения стабилизируется на конкретном числе — это и есть мгновенная скорость]

Эта идея — переход от средней скорости к мгновенной через предел — и есть содержание определения производной. Только заменим “скорость” на абстрактное “скорость изменения функции”, а $s(t)$ — на произвольную функцию $f(x)$.

#### Геометрический смысл: наклон касательной

Посмотрим на график функции $f(x)$. Возьмём две точки на графике: $(x, f(x))$ и $(x + \Delta x, f(x + \Delta x))$. Прямая, проведённая через них, называется секущей. Её наклон — это отношение приращения функции к приращению аргумента:

$$ k_{\text{сек}} = \frac{f(x + \Delta x) - f(x)}{\Delta x}. $$

Это та же самая «средняя скорость», только теперь выраженная геометрически как тангенс угла наклона секущей.

Что произойдёт, если мы будем уменьшать $\Delta x$, заставляя вторую точку «сползать» по графику к первой? Секущая будет поворачиваться, и в пределе превратится в касательную — прямую, которая касается графика в точке $x$. Наклон этой касательной — это геометрический смысл производной.

[АНИМАЦИЯ: на графике функции $f(x) = x^2$ зафиксирована точка $A = (1, 1)$, через неё и вторую точку $B = (1 + \Delta x, f(1 + \Delta x))$ проведена секущая; $\Delta x$ постепенно уменьшается от $1$ до $0$, точка $B$ съезжает к $A$, а секущая плавно превращается в касательную; рядом отображается численное значение наклона]

Теперь мы готовы дать строгое определение.

{% capture notice %}
**Определение (производная)**. Производной функции $f$ в точке $x_0$ называется предел

$$ f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}, $$

если этот предел существует и конечен. Функция, имеющая производную в точке, называется дифференцируемой в этой точке.
{% endcapture %}

Для производной существует несколько обозначений: $f'(x)$ (Лагранжа), $\dfrac{df}{dx}$ (Лейбница), $\dot f$ (Ньютона, обычно для производной по времени). Все они означают одно и то же; запись Лейбница особенно удобна, потому что в ней буквально читается «отношение бесконечно малого приращения функции к бесконечно малому приращению аргумента».

[КАРТИНКА: график функции с тремя касательными в разных точках — там, где функция круто растёт (касательная сильно наклонена вверх), там, где она достигает максимума (касательная горизонтальна, наклон равен нулю), и там, где функция убывает (касательная наклонена вниз)]

#### Алгоритмический смысл: численное дифференцирование

Если производная — это предел отношения, значит, его можно приближённо вычислить, не переходя к пределу, а просто взяв очень маленькое $\Delta x$. Это и есть численное дифференцирование — самый прямолинейный способ получить производную, не зная её формулы.

```py
def numerical_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x)) / h

f = lambda x: x ** 2  # производная: f'(x) = 2x

for x0 in [0.0, 1.0, 2.0, -3.0]:
    approx = numerical_derivative(f, x0)
    exact  = 2 * x0
    print(f"x={x0:+.1f} | численно: {approx:+.6f} | точно: {exact:+.1f}")

# x=+0.0 | численно: +0.000010 | точно: +0.0
# x=+1.0 | численно: +2.000010 | точно: +2.0
# x=+2.0 | численно: +4.000010 | точно: +4.0
# x=-3.0 | численно: -5.999990 | точно: -6.0
```

Эта простая формула — буквальная реализация определения. Численное дифференцирование незаменимо для проверки градиентов (gradient checking) при разработке нейросетей: если вы реализовали backprop вручную, можно сверить аналитический градиент с численным и убедиться, что код корректен.

На практике используют центральную разностную схему, которая в два раза точнее:

$$ f'(x) \approx \frac{f(x + h) - f(x - h)}{2h}. $$

```py
def central_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

f = lambda x: np.sin(x)

for x0 in [0.0, np.pi/4, np.pi/2]:
    approx = central_derivative(f, x0)
    exact  = np.cos(x0)
    print(f"x={x0:.4f} | прибл.: {approx:.8f} | точно: {exact:.8f}")

# x=0.0000 | прибл.: 1.00000000 | точно: 1.00000000
# x=0.7854 | прибл.: 0.70710678 | точно: 0.70710678
# x=1.5708 | прибл.: 0.00000000 | точно: 0.00000000
```

Все восемь знаков после запятой совпадают — центральная схема даёт почти идеальный результат при разумных $h$.

#### Алгебраический смысл: линейное приближение

Есть ещё одна — пожалуй, самая глубокая — интерпретация производной. Перепишем определение в эквивалентной форме:

$$ f(x_0 + \Delta x) = f(x_0) + f'(x_0)\,\Delta x + o(\Delta x), \quad \Delta x \to 0. $$

Это называется **формулой линейного приближения** или дифференциалом первого порядка. Она говорит: вблизи точки $x_0$ функция $f$ ведёт себя почти как линейная, и коэффициент при $\Delta x$ — это и есть производная.

То есть производная — это коэффициент наилучшего линейного приближения функции вблизи точки. Это объясняет геометрический смысл (касательная — это и есть это приближение, изображённое как прямая) и подсказывает практическую идею: если мы знаем $f(x_0)$ и $f'(x_0)$, мы можем приближённо предсказать $f(x_0 + \Delta x)$ для маленьких $\Delta x$, не вычисляя её заново.

В машинном обучении это идея локальной линеаризации — основа теории Neural Tangent Kernel, метода Ньютона, методов второго порядка и многих теоретических анализов нейросетей.

[КАРТИНКА: график функции $f(x) = e^x$ и её касательной $y = 1 + x$ в точке $x_0 = 0$; на интервале вокруг нуля видно, что эти две линии почти неразличимы, а вдали — расходятся; подсвечен «зазор» $o(\Delta x)$]

```py
f = np.exp
x0 = 0.0
fx0 = f(x0)        # 1.0
fpx0 = np.exp(x0)  # производная exp в нуле = 1

for dx in [1.0, 0.1, 0.01, 0.001]:
    exact  = f(x0 + dx)
    linear = fx0 + fpx0 * dx
    print(f"dx={dx:.3f} | точно: {exact:.6f} | линейное: {linear:.6f} | ошибка: {exact - linear:.2e}")

# dx=1.000 | точно: 2.718282 | линейное: 2.000000 | ошибка: 7.18e-01
# dx=0.100 | точно: 1.105171 | линейное: 1.100000 | ошибка: 5.17e-03
# dx=0.010 | точно: 1.010050 | линейное: 1.010000 | ошибка: 5.02e-05
# dx=0.001 | точно: 1.001001 | линейное: 1.001000 | ошибка: 5.00e-07
```

Каждое уменьшение $\Delta x$ в 10 раз даёт уменьшение ошибки в 100 раз — это типичное поведение для линейного приближения, где остаток имеет порядок $O(\Delta x^2)$.

#### Связь дифференцируемости и непрерывности

Есть важное соотношение между двумя классами «хороших» функций:

Теорема. Если функция $f$ дифференцируема в точке $x_0$, то она непрерывна в этой точке. Обратное неверно.

Иными словами, дифференцируемость сильнее непрерывности. Самый известный контрпример — $f(x) = \mid x\mid$: она непрерывна везде, но в нуле имеет острый угол, и производной там не существует (левый и правый пределы отношения $\Delta f / \Delta x$ дают разные значения: $-1$ и $+1$).

[КАРТИНКА: график $f(x) = \mid x\mid$ с подсвеченной точкой излома в нуле; рядом — график производной $f'(x) = \mathrm{sign}(x)$ со скачком в нуле, иллюстрирующий, что производная в этой точке не определена]

Это прямо влияет на ML. Функция активации ReLU $\max(0, x)$ ведёт себя ровно так же — у неё излом в нуле. Поэтому формально она недифференцируема, и приходится использовать субградиент (обобщение производной на негладкие функции). На практике принимают $\mathrm{ReLU}'(0) = 0$ (или $1$) — этого достаточно для работы оптимизаторов.

#### Производная как функция

Если производная существует во всех точках области определения, то $f'(x)$ сама становится функцией от $x$. Эту функцию можно дифференцировать снова, получая вторую производную $f''(x)$, потом третью, и так далее. Вторая производная $f''(x)$ имеет физический смысл ускорения (скорость изменения скорости), а геометрический — кривизны графика. В оптимизации именно знак $f''(x)$ определяет, является ли точка $x$ с условием $f'(x) = 0$ минимумом ($f''(x) > 0$) или максимумом ($f''(x) < 0$).

```py
f  = lambda x: x**3 - 3*x        # f'(x) = 3x^2 - 3, нули в x = ±1
fp = lambda x: 3*x**2 - 3

for x0 in [-2, -1, 0, 1, 2]:
    print(f"x={x0:+d} | f(x)={f(x0):+.0f} | f'(x)={fp(x0):+.0f}")

# x=-2 | f(x)=-2 | f'(x)=+9
# x=-1 | f(x)=+2 | f'(x)=+0
# x=+0 | f(x)=+0 | f'(x)=-3
# x=+1 | f(x)=-2 | f'(x)=+0
# x=+2 | f(x)=+2 | f'(x)=+9
```

В точках $x = \pm 1$ производная обращается в ноль — это критические точки, где функция имеет локальный максимум (при $x = -1$) или минимум (при $x = 1$). Именно поиском таких точек занимаются все алгоритмы оптимизации.

[КАРТИНКА: на одних осях — график $f(x) = x^3 - 3x$ и его производная $f'(x) = 3x^2 - 3$; вертикальные пунктирные линии в точках $x = \pm 1$ соединяют экстремумы $f$ с нулями $f'$, наглядно демонстрируя необходимое условие экстремума]

#### Зачем производная нужна в машинном обучении

Подведём практический итог. Когда мы обучаем модель, мы минимизируем функцию потерь $L(\theta)$ по параметрам $\theta$. Производная $L'(\theta)$ говорит нам, в какую сторону и насколько круто меняется $L$ при изменении $\theta$. Алгоритм обновления параметров — градиентный спуск — буквально читает эту информацию: $\theta \leftarrow \theta - \eta \cdot L'(\theta)$. Если производная положительна, мы уменьшаем $\theta$; если отрицательна — увеличиваем. Размер шага $\eta$ (learning rate) определяет, насколько сильно мы доверяем линейному приближению — слишком большой шаг вылетит за пределы зоны, где приближение хорошее, и обучение разойдётся.

Помимо оптимизации, производные используются в анализе чувствительности (как изменение признака влияет на предсказание), в методах объяснения моделей (Saliency Maps, Integrated Gradients), в adversarial-атаках (где мы максимизируем функцию потерь по входу) и в дифференциальных уравнениях, описывающих модели вроде Neural ODE.

#### Краткие итоги

- Производная $f'(x_0)$ — это предел отношения приращения функции к приращению аргумента при стремлении последнего к нулю.
- Геометрический смысл: производная — наклон касательной к графику функции в точке.
- Физический смысл: производная — мгновенная скорость изменения функции; обобщение понятия скорости из механики на любую функцию.
- Алгебраический смысл: производная — коэффициент наилучшего линейного приближения функции вблизи точки: $f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\,\Delta x$.
- Численное дифференцирование — простой способ оценить производную через малое приращение; центральная разностная схема даёт лучшую точность.
- **Дифференцируемость влечёт непрерывность, но не наоборот**: функции с изломами (как $\mid x\mid $ или ReLU) могут быть непрерывны, но не иметь производной в точке излома.
- Вторая производная характеризует кривизну графика и позволяет различать минимумы и максимумы; в многомерном случае её аналог — матрица Гессиана.
- Критические точки (где $f'(x) = 0$) — кандидаты в экстремумы; именно их ищут алгоритмы оптимизации.
- В машинном обучении производная — рабочий инструмент градиентного спуска, обратного распространения ошибки, анализа чувствительности, методов интерпретации моделей и adversarial-атак.
- Все три интерпретации (геометрическая, физическая, алгебраическая) описывают одну и ту же сущность; владение всеми тремя даёт максимально глубокое понимание.

В следующей главе мы научимся вычислять производные не через предел, а с помощью готовых правил — производных элементарных функций, формул для суммы, произведения, частного и, главное, правила цепочки (chain rule), которое лежит в основе алгоритма обратного распространения ошибки в нейросетях.


### Дифференцируемость и приближение линейной функцией (CO)

Когда мы говорим о производной функции одной переменной, мы обычно представляем себе касательную к графику в точке. Эта картинка содержит в себе гораздо больше смысла, чем кажется на первый взгляд. На самом деле, идея производной — это идея локального приближения сложной функции простой. И именно эта идея лежит в основе практически всего машинного обучения: от градиентного спуска до обратного распространения ошибки в нейронных сетях.

Давайте разберёмся, что такое дифференцируемость по-настоящему, и почему её правильнее всего понимать через линейное приближение.

#### От производной к линейному приближению

Из школьного курса мы помним определение производной как предела отношения приращений:

$$
f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}
$$

Это определение операционное — оно говорит, как считать производную. Но оно не очень хорошо объясняет, что такое производная по смыслу. Гораздо более глубокий взгляд даёт следующая переформулировка. Перенесём $f(x_0)$ налево и умножим на $h$:

$$
f(x_0 + h) = f(x_0) + f'(x_0) \cdot h + o(h)
$$

Здесь $o(h)$ — это «маленькая поправка», которая стремится к нулю быстрее, чем сам $h$. Если мы её отбросим, то получим приближённое равенство:

$$
f(x_0 + h) \approx f(x_0) + f'(x_0) \cdot h
$$

Правая часть — это линейная функция от приращения $h$. То есть мы заменили сложную функцию $f$ вблизи точки $x_0$ на простую линейную функцию. Если посмотреть на график, то эта линейная функция — не что иное, как касательная прямая.

[КАРТИНКА: график нелинейной функции (например, $f(x) = x^2$ или синусоиды) с касательной прямой в точке $x_0$. Стрелочкой показано приращение $h$, и видно, что значение касательной в точке $x_0 + h$ очень близко к значению самой функции, причём чем меньше $h$, тем ближе.]

Эта картинка — ключевая. Дифференцируемость — это, по сути, утверждение о том, что вблизи точки функция выглядит как прямая. Чем ближе мы подходим к точке, тем меньше отличие между функцией и её касательной.

[АНИМАЦИЯ: камера приближается («зумится») к точке на графике гладкой функции. По мере приближения кривая становится всё более похожей на прямую линию. В пределе мы видим только прямую — это и есть касательная.]

#### Формальное определение дифференцируемости

Теперь мы готовы дать строгое определение, которое лучше всего отражает суть.

{% capture notice %}
Определение (дифференцируемость в точке). Функция $f: \mathbb{R} \to \mathbb{R}$ называется дифференцируемой в точке $x_0$, если существует такое число $A$, что

$$
f(x_0 + h) = f(x_0) + A \cdot h + o(h), \quad h \to 0,
$$

где $o(h)$ означает функцию, удовлетворяющую условию $\lim_{h \to 0} \frac{o(h)}{h} = 0$. Число $A$ называется производной функции $f$ в точке $x_0$ и обозначается $f'(x_0)$.
{% endcapture %}
{{ notice | markdownify }}

Это определение можно прочесть так: «функция дифференцируема, если её можно приблизить линейной функцией с точностью до бесконечно малой высшего порядка». Само число $f'(x_0)$ — это коэффициент наклона той самой касательной прямой.

Обратите внимание: это определение легко обобщается на функции многих переменных, на векторнозначные функции и даже на отображения между произвольными пространствами. Просто $A$ становится не числом, а линейным оператором. Именно поэтому это определение так важно для машинного обучения — оно даёт единый язык для разговора о производных в любой размерности.

#### Геометрический смысл и связь с касательной

Касательная прямая в точке $x_0$ задаётся уравнением:

$$
L(x) = f(x_0) + f'(x_0)(x - x_0)
$$

Это и есть наше линейное приближение. Если обозначить $h = x - x_0$, мы получаем ту же самую формулу, что и выше.

[КАРТИНКА: два графика рядом. Слева — функция $f(x) = e^x$ с касательной в точке $x_0 = 0$ (касательная — прямая $y = 1 + x$). Справа — та же картинка, но с увеличением в окрестности $x_0 = 0$, чтобы было видно, как близко прямая и кривая.]

Важное наблюдение: чем «более гладкая» функция, тем лучше её приближает касательная. У функции с резким изломом (например, $f(x) = |x|$ в нуле) производной просто не существует — в окрестности точки нет ни одной прямой, которая приближала бы её достаточно хорошо.

[КАРТИНКА: график функции $f(x) = |x|$. Показано, что в точке $x_0 = 0$ нельзя провести единственную касательную: слева и справа наклоны разные. Это пример недифференцируемой функции.]

#### Проверяем определение в коде

Давайте на практике увидим, что производная — это действительно коэффициент линейного приближения. Возьмём функцию $f(x) = x^2$ и точку $x_0 = 1$. Аналитически $f'(1) = 2$. Проверим это численно, используя само определение.

```py
def f(x):
    return x**2

x0 = 1.0
for h in [0.1, 0.01, 0.001, 0.0001]:
    approx = (f(x0 + h) - f(x0)) / h
    print(f"h = {h:7.4f}  ->  (f(x0+h) - f(x0))/h = {approx:.6f}")
```

Вывод:

h =  0.1000  ->  (f(x0+h) - f(x0))/h = 2.100000
h =  0.0100  ->  (f(x0+h) - f(x0))/h = 2.010000
h =  0.0010  ->  (f(x0+h) - f(x0))/h = 2.001000
h =  0.0001  ->  (f(x0+h) - f(x0))/h = 2.000100


Видим, как отношение приращений сходится к числу $2$ — именно к $f'(1)$. А теперь оценим ошибку линейного приближения, то есть величину $o(h)$:

```py
fprime = 2.0
for h in [0.1, 0.01, 0.001, 0.0001]:
    linear = f(x0) + fprime * h
    error  = f(x0 + h) - linear
    print(f"h = {h:7.4f}  ошибка = {error:.8f}  ошибка/h = {error/h:.6f}")
```

Вывод:

h =  0.1000  ошибка = 0.01000000  ошибка/h = 0.100000
h =  0.0100  ошибка = 0.00010000  ошибка/h = 0.010000
h =  0.0010  ошибка = 0.00000100  ошибка/h = 0.001000
h =  0.0001  ошибка = 0.00000001  ошибка/h = 0.000100


Замечательно: ошибка приближения уменьшается быстрее, чем сам $h$ — отношение ошибки к $h$ стремится к нулю. Это и есть в действии та самая малая величина $o(h)$ из определения. На практике мы только что увидели дифференцируемость.

#### Связь с дифференциалом

Линейную часть приращения называют дифференциалом функции в точке.

{% capture notice %}
**Определение (дифференциал)**. Дифференциалом функции $f$ в точке $x_0$ называется линейная функция приращения $h$:

$$
df_{x_0}(h) = f'(x_0) \cdot h
$$

Тогда $f(x_0 + h) - f(x_0) = df_{x_0}(h) + o(h)$.
{% endcapture %}
{{ notice | markdownify }}

Дифференциал — это «линейный кусочек» изменения функции. Если $h$ маленькое, то $df_{x_0}(h)$ почти полностью описывает, насколько изменится $f$. Это не просто игра в обозначения: в многомерном случае дифференциал станет линейным отображением — матрицей Якоби, — и именно с ним мы будем работать в нейронных сетях.

[КАРТИНКА: график функции $f$ с касательной. Показаны два вертикальных отрезка: реальное приращение функции $\Delta f = f(x_0+h) - f(x_0)$ и дифференциал $df = f'(x_0) h$ (приращение вдоль касательной). Маленький отрезок между ними подписан как $o(h)$.]

#### Зачем это в машинном обучении

Дифференцируемость — это не абстрактная математическая роскошь, а инженерный фундамент машинного обучения.

Первое. Алгоритм градиентного спуска, на котором обучаются почти все современные модели (от логистической регрессии до GPT), напрямую использует линейное приближение функции потерь. Когда мы говорим «сделай маленький шаг в сторону, противоположную градиенту», мы по сути верим, что вблизи текущей точки функция потерь похожа на свою линейную аппроксимацию, а значит мы можем предсказать, как изменится ошибка.

Второе. Обратное распространение ошибки в нейронных сетях — это применение цепного правила, которое работает именно благодаря дифференцируемости. Если хоть один слой сети будет недифференцируемым, обучить сеть стандартными методами невозможно.

Третье. Понимание $o(h)$-приближения объясняет, почему в нейросетях так важно выбирать малую скорость обучения (learning rate). Если шаг слишком большой, линейное приближение перестаёт работать, и мы можем «перепрыгнуть» минимум или вообще уйти в сторону.

Продемонстрируем это последнее наблюдение на практике. Сравним истинное изменение функции потерь $L(w) = (w - 3)^2$ и его линейное предсказание при разных шагах:

```py
def L(w):
    return (w - 3)**2

def dL(w):
    return 2 * (w - 3)

w0 = 0.0
grad = dL(w0)
for step in [0.01, 0.1, 1.0, 3.0]:
    w_new   = w0 - step * grad
    real    = L(w_new) - L(w0)
    linear  = -step * grad * grad   # = grad * (w_new - w0)
    print(f"step={step:4} | real ΔL={real:8.3f} | linear ΔL={linear:8.3f}")
```

Вывод:

step=0.01 | real ΔL=  -0.356 | linear ΔL=  -0.360
step=0.1  | real ΔL=  -3.240 | linear ΔL=  -3.600
step=1.0  | real ΔL=   0.000 | linear ΔL= -36.000
step=3.0  | real ΔL= 261.000 | linear ΔL=-108.000


При маленьком шаге линейное приближение работает почти идеально. При шаге $1.0$ оно уже сильно врёт. А при шаге $3.0$ функция потерь не только не уменьшилась, но и катастрофически выросла — линейное приближение обещало уменьшение на $108$, а получили рост на $261$! Это и есть наглядная демонстрация того, почему learning rate должен быть достаточно мал: иначе мы выходим за пределы зоны, где работает линейное приближение.

[КАРТИНКА: парабола $L(w)$ с тремя стрелками шагов градиентного спуска из точки $w_0 = 0$: маленькая стрелка остаётся вблизи касательной, средняя уже отклоняется, большая «выстреливает» вверх по параболе. Касательная нарисована пунктиром для сравнения.]

#### Выводы

Производная — это не просто «скорость изменения», а коэффициент наилучшего линейного приближения функции в точке.
Функция дифференцируема в точке тогда и только тогда, когда её можно представить в виде $f(x_0 + h) = f(x_0) + A h + o(h)$, и тогда $A = f'(x_0)$.
Геометрически дифференцируемость означает, что у графика функции в точке есть касательная, и при увеличении окрестность точки выглядит как прямая.
Дифференциал $df_{x_0}(h) = f'(x_0) h$ — это линейная часть приращения; в многомерном случае он обобщается до линейного оператора и становится основой для матрицы Якоби и обратного распространения ошибки.
Машинное обучение почти полностью построено на идее линейного приближения: градиентный спуск работает, пока шаги остаются в зоне, где линейная аппроксимация адекватна.
Недифференцируемые точки (изломы, разрывы) — это места, где стандартные методы оптимизации ломаются, и с ними нужно работать особыми приёмами (субградиенты, сглаживание, и т.д.).

### Дифференцируемость и приближение линейной функцией (DS)

Представьте, что мы смотрим на гладкую кривую через очень мощное увеличительное стекло. Что мы увидим? Какой бы изогнутой ни казалась функция издалека, вблизи конкретной точки её график становится почти неотличимым от прямой. Именно это свойство — **локальная линейность** — лежит в основе понятия дифференцируемости. Для специалиста по машинному обучению умение заменить сложную нелинейную зависимость простым линейным приближением — ключевой навык. Вся современная оптимизация, от градиентного спуска до обучения гигантских нейросетей, построена на том, что в малой окрестности текущего приближения функция потерь ведёт себя как линейная.

#### Производная как мгновенная скорость изменения

Рассмотрим функцию $f: \mathbb{R} \to \mathbb{R}$ и точку $a$. Если мы хотим понять, насколько быстро меняется $f$ вблизи $a$, естественно взять небольшое приращение $h$, вычислить изменение значения функции $f(a+h)-f(a)$ и разделить его на длину шага $h$. Полученная величина $\frac{f(a+h)-f(a)}{h}$ — это средняя скорость изменения $f$ на промежутке $[a, a+h]$, то есть угловой коэффициент секущей, соединяющей точки $(a, f(a))$ и $(a+h, f(a+h))$.

Чтобы узнать мгновенную скорость в самой точке $a$, мы уменьшаем шаг, устремляя $h$ к нулю. Секущая при этом поворачивается и в пределе превращается в касательную. Предел, если он существует и конечен, называется производной $f$ в $a$:

$$
f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}.
$$

{% capture notice %}
**Определение (производная).** Пусть функция $f$ определена в некоторой окрестности точки $a$. Если существует конечный предел

$$
f'(a) = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h},
$$

то он называется производной функции $f$ в точке $a$. Функцию, имеющую производную в $a$, называют дифференцируемой в этой точке.
{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

Геометрически производная — это тангенс угла наклона касательной к графику $f$ в точке $(a, f(a))$. Но ещё важнее алгебраическая интерпретация: $f'(a)$ — это коэффициент линейного приближения функции вблизи $a$.

[КАРТИНКА: график гладкой функции (например, $f(x)=x^2$) с отмеченной точкой $a=1$. Нарисована секущая через точки $(1,1)$ и $(1.5,2.25)$, и касательная в $(1,1)$. Стрелка показывает, как при уменьшении $h$ секущая стремится к касательной.]

[АНИМАЦИЯ: последовательность кадров, на которых $h \to 0$. Секущая плавно поворачивается и в пределе совпадает с касательной. Чётко видно, что угловой коэффициент секущей приближается к значению производной.]

#### Дифференцируемость и локальная линейность

Запишем уравнение касательной в точке $a$:

$$
L(x) = f(a) + f'(a)(x-a).
$$

Если $f$ дифференцируема в $a$, то при $x$, близких к $a$, значения $f(x)$ и $L(x)$ почти неразличимы. Более строго: разность $f(x) - L(x)$ стремится к нулю быстрее, чем $x-a$. Это записывают с помощью символа $o(h)$ («о малое от $h$»), который обозначает величину, делённую на $h$ стремящуюся к нулю при $h \to 0$:

$$
f(a+h) = f(a) + f'(a)h + o(h), \quad h\to 0.
$$

Такая запись говорит: функция вблизи $a$ есть сумма константы $f(a)$, линейного члена $f'(a)h$ и пренебрежимо малого остатка. Именно это свойство называется **дифференцируемостью**.

{% capture notice %}
**Определение (дифференцируемость через линейное приближение).** Функция $f$ называется дифференцируемой в точке $a$, если существует такое число $A$, что для всех достаточно малых $h$ выполняется

$$
f(a+h) = f(a) + A h + o(h) \quad \text{при } h\to 0.
$$

Число $A$ при этом обязательно равно $f'(a)$.
{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

Иными словами, под микроскопом график дифференцируемой функции неотличим от прямой. На рисунке ниже показан график $f(x)=x^3$ вблизи $x=1$ и касательная $y=3x-2$. Даже при небольшом увеличении кривая и прямая практически сливаются.

[КАРТИНКА: два графика рядом. Слева — $f(x)=x^3$ на отрезке $[0.5, 1.5]$, касательная в $x=1$. Справа — увеличенный фрагмент в малой окрестности $x=1$, где график функции и прямая визуально совпадают. Дополнительно можно показать график ошибки $f(x)-L(x)$, которая ведёт себя как квадратичная функция, уходящая в ноль быстрее линейного члена.]

#### Почему не все функции дифференцируемы?

Не любая кривая распрямляется при увеличении. Классический пример — функция модуля $f(x)=|x|$ в нуле. Секущие слева и справа приближаются к разным прямым: левосторонний предел $\frac{|0+h|-0}{h}$ при $h\to 0^-$ равен $-1$, правосторонний — $1$. Общего предела не существует, поэтому у $|x|$ в нуле нет производной, а значит, нет и хорошего линейного приближения — график имеет излом.

[КАРТИНКА: график $f(x)=|x|$. В точке $0$ показаны две полукасательные с разными наклонами. Подпись: «излом не допускает единой касательной».]

В машинном обучении мы предпочитаем дифференцируемые функции потерь именно потому, что изломы лишают нас информации о направлении наискорейшего убывания. Впрочем, для выпуклых негладких функций существует понятие субградиента, позволяющее обобщить градиентные методы, но это тема продвинутого курса.

#### Линейное приближение в коде: от ручной реализации к автодифференцированию

Численное вычисление производной проще всего сделать методом центральной конечной разности: для малого $h$ (например, $10^{-5}$) положим

$$
f'(a) \approx \frac{f(a+h)-f(a-h)}{2h}.
$$

Этот способ даёт точность порядка $O(h^2)$ и легко программируется.

```python
import numpy as np

def derivative(f, x, h=1e-5):
    """Численная производная f'(x) центральной разностью."""
    return (f(x + h) - f(x - h)) / (2 * h)

# Пример: f(x) = x^3 в точке x=2
f = lambda x: x**3
x0 = 2.0
df_num = derivative(f, x0)
df_true = 3 * x0**2
print(f"Численная производная в x=2: {df_num:.5f}")
print(f"Аналитическая производная:     {df_true:.5f}")

# Построим линейное приближение L(x) = f(x0) + f'(x0)*(x-x0)
def linear_approx(x):
    return f(x0) + df_num * (x - x0)

h_test = 0.1
print(f"\nf({x0+h_test}) = {f(x0+h_test):.5f}")
print(f"L({x0+h_test}) = {linear_approx(x0+h_test):.5f}")
print(f"Ошибка = {abs(f(x0+h_test)-linear_approx(x0+h_test)):.6f}")
```

Вывод:
```
Численная производная в x=2: 12.00000
Аналитическая производная:     12.00000

f(2.1) = 9.26100
L(2.1) = 9.20000
Ошибка = 0.061000
```

При уменьшении $h_{test}$ ошибка будет уменьшаться пропорционально $h_{test}^2$, подтверждая локальную линейность.

В библиотеках глубокого обучения применяется **автоматическое дифференцирование**: программа отслеживает последовательность элементарных операций и применяет цепное правило. Вот как вычислить ту же производную с помощью PyTorch:

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
f_val = x**3
f_val.backward()          # автоматически вычисляет градиент
print(f"Автоградиент PyTorch: {x.grad.item():.5f}")
```

Вывод:

```
Автоградиент PyTorch: 12.00000
```

Как видим, результат совпадает. В реальных моделях такой подход позволяет вычислять градиенты функций потерь по миллионам параметров — всё благодаря тому, что каждая элементарная операция дифференцируема.

#### Связь с машинным обучением: градиентный спуск для одного параметра

Рассмотрим простейшую задачу обучения: у нас есть единственный вес $w$, и мы хотим минимизировать квадратичную ошибку $L(w)=(w-3)^2$. Аналитически минимум очевиден ($w=3$), но градиентный спуск демонстрирует общий принцип. Вычислим производную $L'(w)=2(w-3)$. Правило обновления:

$$
w_{t+1} = w_t - \eta L'(w_t),
$$

где $\eta$ — скорость обучения. Идея опирается как раз на линейное приближение: в окрестности $w_t$

$$
L(w_t + \Delta w) \approx L(w_t) + L'(w_t)\Delta w.
$$

Выбирая $\Delta w = -\eta L'(w_t)$, мы гарантируем, что линейная часть уменьшится: $L'(w_t)\Delta w = -\eta [L'(w_t)]^2 \le 0$.

Реализуем спуск, используя нашу численную производную, чтобы подчеркнуть универсальность подхода:

```python
def gradient_descent_step(f, w, lr=0.1):
    grad = derivative(f, w)         # численный градиент
    return w - lr * grad, grad

L = lambda w: (w - 3)**2
w = 0.0
print("Градиентный спуск (численная производная):")
for i in range(10):
    w, grad = gradient_descent_step(L, w, lr=0.5)
    print(f"Шаг {i+1}: w = {w:.4f}, L(w) = {L(w):.4f}, grad ≈ {grad:.4f}")
```

Вывод:

```
Градиентный спуск (численная производная):
Шаг 1: w = 3.0000, L(w) = 0.0000, grad ≈ -6.0000
Шаг 2: w = 3.0000, L(w) = 0.0000, grad ≈ -0.0000
...
```

Для квадратичной функции метод сходится мгновенно при $\eta=0.5$, но для более сложных $L(w)$ итерации постепенно приближают $w$ к оптимуму. Именно эту стратегию используют все современные оптимизаторы (Adam, SGD и др.), обобщая её на многомерный случай.

[АНИМАЦИЯ: график параболы $L(w)=(w-3)^2$. Анимированный шарик начинает из точки $w=0$ и скатывается по склону к минимуму. На каждом кадре показана касательная в текущей точке, чей наклон определяет направление и величину шага. Траектория быстро сходится.]

#### Заключение

- **Дифференцируемость** функции одной переменной означает существование конечной производной, что эквивалентно возможности хорошо приблизить функцию линейной зависимостью в малой окрестности точки: $f(a+h) \approx f(a) + f'(a)h$.
- Геометрически производная — это наклон касательной, а линейное приближение — сама эта касательная.
- Свойство локальной линейности позволяет заменить сложную функцию простой прямой при анализе поведения возле точки, на чём основан градиентный спуск: мы движемся в направлении наискорейшего убывания, вычисленном по производной.
- Не все функции дифференцируемы (например, $|x|$ в нуле); в машинном обучении мы сознательно выбираем гладкие функции потерь или прибегаем к обобщениям вроде субградиента.
- Численно производную можно получить конечными разностями, а в библиотеках глубокого обучения — автоматическим дифференцированием, которое эффективно применяет цепное правило к композициям элементарных операций.

### Правила дифференцирования и производные элементарных функций (CO)

В предыдущей главе мы выяснили, что производная — это коэффициент линейного приближения функции в точке. Но если каждый раз, когда нам нужна производная, считать предел по определению, мы быстро устанем. К счастью, существует небольшой набор правил дифференцирования и таблица производных элементарных функций, которые позволяют находить производные практически любых выражений механически, как сборку из конструктора. Именно так устроены все системы автоматического дифференцирования внутри PyTorch и TensorFlow: они знают производные базовых функций и умеют комбинировать их по правилам.

Давайте разберём эти правила так, чтобы они стали не магическими формулами для заучивания, а очевидными следствиями определения производной.

#### Производная как линейный оператор: линейность дифференцирования

Первое и самое важное свойство производной — её линейность. Если у нас есть две функции $f(x)$ и $g(x)$, то производная их суммы равна сумме производных, а константу можно вынести за знак производной.

{% capture notice %}
**Свойство (линейность производной)**. Если функции $f$ и $g$ дифференцируемы в точке $x$, а $\alpha, \beta \in \mathbb{R}$ — константы, то

$$
(\alpha f(x) + \beta g(x))' = \alpha f'(x) + \beta g'(x)
$$

{% endcapture %}
{{ notice | markdownify }}

Интуитивно это совершенно очевидно: если мы приближаем каждую функцию своей касательной, то сумма функций приближается суммой касательных. А умножение на константу — это просто масштабирование, которое в равной мере масштабирует и саму функцию, и её приращение, и её производную.

[КАРТИНКА: три графика на одной плоскости. Синий — $f(x) = x^2$, красный — $g(x) = \sin x$, зелёный — их сумма $f(x) + g(x)$. В одной и той же точке проведены три касательные, и видно, что наклон зелёной касательной равен сумме наклонов синей и красной.]

Это свойство — основа линейной регрессии и любой задачи, где функция потерь представляется как сумма ошибок по объектам выборки: $L(w) = \sum_{i=1}^{N} \ell_i(w)$. Производная такой суммы равна сумме производных, поэтому градиент по всей выборке — это просто сумма градиентов по отдельным примерам. Именно на этом построен стохастический градиентный спуск: вместо того чтобы суммировать миллион слагаемых, мы берём одно случайное и приближённо оцениваем градиент.

Проверим линейность численно, считая производную по определению:

```py
def numeric_deriv(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

import math
f = lambda x: x**2
g = lambda x: math.sin(x)
h = lambda x: 3*f(x) + 2*g(x)

x0 = 1.0
print("3*f' + 2*g' =", 3*numeric_deriv(f, x0) + 2*numeric_deriv(g, x0))
print("(3f + 2g)' =", numeric_deriv(h, x0))
```

Вывод:

3*f' + 2*g' = 7.080604611736162
(3f + 2g)' = 7.080604611736158


Значения совпадают до десятого знака — линейность работает.

#### Производные элементарных функций

Любая сложная функция в машинном обучении в конечном счёте строится из небольшого набора кирпичиков: степенных функций, экспоненты, логарифма, тригонометрии. Их производные нужно знать наизусть — это таблица умножения дифференциального исчисления.

{% capture notice %}
Таблица производных элементарных функций.

$$
\begin{aligned}
(c)' &= 0, \quad (c \in \mathbb{R}) \\
(x^n)' &= n \cdot x^{n-1} \\
(e^x)' &= e^x \\
(a^x)' &= a^x \ln a \\
(\ln x)' &= \frac{1}{x} \\
(\sin x)' &= \cos x \\
(\cos x)' &= -\sin x
\end{aligned}
$$

{% endcapture %}
{{ notice | markdownify }}

Каждая из этих формул имеет глубокий смысл. Производная константы равна нулю, потому что её график — горизонтальная прямая, и она никак не меняется. Производная $x^n$ описывает, как быстро растут полиномы — основа полиномиальной регрессии. Экспонента вообще уникальна: $(e^x)' = e^x$, то есть скорость её роста в каждой точке равна её собственному значению. Именно поэтому экспонента и её родственник — функция softmax — повсеместно используются в нейронных сетях: они моделируют процессы с самоусиливающимся ростом.

[КАРТИНКА: четыре графика рядом. Слева направо: $x^2$ с касательной (наклон $2x$), $e^x$ с касательной (наклон равен высоте графика — видно, что треугольник касательной растёт вместе с функцией), $\ln x$ с касательной (наклон уменьшается как $1/x$), $\sin x$ с касательной (наклон осциллирует и равен $\cos x$).]

Логарифм $\ln x$ — обратный к экспоненте, и его производная $1/x$ объясняет, почему в задачах классификации мы так часто видим логарифмическую функцию потерь (cross-entropy): она «штрафует» уверенно неверные предсказания крайне сильно, ведь $\ln x \to -\infty$ при $x \to 0$, а её градиент $1/x$ становится огромным.

Давайте проверим табличные формулы численно:

```py
import math

    "x^3":    (lambda x: x**3,     lambda x: 3*x**2),
    "e^x":    (lambda x: math.exp(x), lambda x: math.exp(x)),
```

#### Произведение и частное

Теперь мы готовы дифференцировать функции, которые получаются перемножением и делением. Здесь интуиция чуть тоньше.

{% capture notice %}
**Правило производной произведения (правило Лейбница)**. Если $f$ и $g$ дифференцируемы в точке $x$, то

$$
(f(x) g(x))' = f'(x) g(x) + f(x) g'(x)
$$

{% endcapture %}
{{ notice | markdownify }}

Откуда берётся такая формула? Представьте площадь прямоугольника со сторонами $f$ и $g$. При малом изменении $x$ обе стороны слегка меняются, и площадь прирастает двумя тонкими полосками: одна площадью $g \cdot \Delta f$, вторая — $f \cdot \Delta g$. Маленьким уголком $\Delta f \cdot \Delta g$ можно пренебречь — он бесконечно малый второго порядка.

[КАРТИНКА: прямоугольник со сторонами $f$ и $g$. Стороны увеличиваются на $\Delta f$ и $\Delta g$. Видно три новых области: вертикальная полоска шириной $\Delta f$ и высотой $g$, горизонтальная полоска шириной $f$ и высотой $\Delta g$, и маленький уголок $\Delta f \cdot \Delta g$ (закрашен бледным цветом — «им пренебрегаем»).]

{% capture notice %}
**Правило производной частного**. Если $g(x) \ne 0$, то

$$
\left( \frac{f(x)}{g(x)} \right)' = \frac{f'(x) g(x) - f(x) g'(x)}{g(x)^2}
$$

{% endcapture %}
{{ notice | markdownify }}

Эти правила работают вместе как маленькая алгебраическая машина. Например, через них выводится производная сигмоиды $\sigma(x) = \frac{1}{1 + e^{-x}}$ — главной активационной функции классической нейронной сети, которая имеет красивый вид $\sigma'(x) = \sigma(x)(1 - \sigma(x))$.

Запрограммируем правило произведения с нуля и сравним с численной производной:

```py
def product_deriv(f, df, g, dg, x):
    return df(x) * g(x) + f(x) * dg(x)

# h(x) = x^2 * sin(x)
f, df = lambda x: x**2,     lambda x: 2*x
g, dg = math.sin,           math.cos
h = lambda x: f(x) * g(x)

x0 = 1.0
print("по правилу Лейбница:", product_deriv(f, df, g, dg, x0))
print("численно:           ", numeric_deriv(h, x0))
```

Вывод:

по правилу Лейбница: 2.2232442919900037
численно:            2.2232442918240226

Совпадение полное. Именно так устроены реализации правил в системах автоматического дифференцирования: каждой операции сопоставлена пара «значение + правило для производной».

#### Цепное правило: производная композиции

Самое важное правило для машинного обучения — цепное правило, или производная сложной функции. Без него не было бы ни обратного распространения ошибки, ни глубокого обучения вообще.

{% capture notice %}
Цепное правило (производная композиции). Если функция $u = g(x)$ дифференцируема в точке $x$, а функция $y = f(u)$ дифференцируема в точке $u = g(x)$, то композиция $y = f(g(x))$ дифференцируема в точке $x$, и

$$
(f(g(x)))' = f'(g(x)) \cdot g'(x)
$$

{% endcapture %}
{{ notice | markdownify }}

Интуиция здесь как у системы шестерёнок. Представьте, что $x$ крутит шестерёнку $g$, которая крутит шестерёнку $f$. Если $x$ повернулся на маленький угол $\Delta x$, то $g$ повернётся на $g'(x) \cdot \Delta x$, а $f$, в свою очередь, повернётся на $f'(g(x))$, умноженное на угол поворота своей входной шестерёнки. В итоге скорости умножаются.

[АНИМАЦИЯ: две сцеплённые шестерёнки. Маленькая (с надписью $g$) крутится со скоростью $g'(x)$, большая (с надписью $f$) сцеплена с ней и крутится со скоростью $f'(g(x)) \cdot g'(x)$. Стрелочка показывает, как изменение $x$ передаётся по цепочке.]

Именно цепное правило стоит за алгоритмом backpropagation: нейронная сеть — это длинная композиция функций $f_n \circ f_{n-1} \circ \dots \circ f_1$, и градиент функции потерь по весам каждого слоя вычисляется через произведение производных всех последующих слоёв. Когда мы говорим «градиент течёт назад через сеть», мы буквально перемножаем эти производные слой за слоем.

Реализуем цепное правило руками и проверим:

```py
# h(x) = sin(x^2),  h'(x) = cos(x^2) * 2x
outer, d_outer = math.sin, math.cos
inner, d_inner = lambda x: x**2, lambda x: 2*x

def chain(x):
    return d_outer(inner(x)) * d_inner(x)

h = lambda x: outer(inner(x))
x0 = 1.3
print("цепное правило:", chain(x0))
print("численно:      ", numeric_deriv(h, x0))
```

Вывод:

цепное правило: -2.0461086818956203
численно:       -2.0461086810848260

Теперь сравним наш ручной расчёт с готовой системой автоматического дифференцирования из PyTorch — внутри неё работают ровно те же правила:

```py
import torch
x = torch.tensor(1.3, requires_grad=True)
y = torch.sin(x**2)
y.backward()
print("PyTorch autograd:", x.grad.item())
```

Вывод:

PyTorch autograd: -2.0461087226867676

Значения идентичны. Это даёт важное понимание: autograd — не магия, а аккуратное применение правила Лейбница, линейности и цепного правила к графу вычислений.

#### Выводы

Производная — линейный оператор: $(\alpha f + \beta g)' = \alpha f' + \beta g'$. На этом построены все суммарные функции потерь и стохастический градиентный спуск.
Таблица производных элементарных функций — это набор «атомов», из которых собираются производные сложных выражений: $(x^n)' = n x^{n-1}$, $(e^x)' = e^x$, $(\ln x)' = 1/x$, $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$.
Правило произведения $(fg)' = f'g + fg'$ и правило частного позволяют дифференцировать рациональные комбинации функций; они выводятся геометрически из изменения площади прямоугольника.
Цепное правило $(f(g(x)))' = f'(g(x)) \cdot g'(x)$ — фундамент обратного распространения ошибки: градиент через многослойную сеть вычисляется перемножением производных её слоёв.
Все системы автоматического дифференцирования (PyTorch, TensorFlow, JAX) внутри устроены как набор табличных производных плюс эти три правила, применяемые к графу вычислений.
Численная производная по определению — удобный инструмент самопроверки аналитических вычислений: значения должны совпадать с точностью до нескольких знаков.

### Правила дифференцирования и производные элементарных функций (DS)

Когда мы говорим, что дифференцируемость позволяет приближать функцию линейной зависимостью, мы полагаемся на умение вычислять эту линейную зависимость — то есть находить производную. Для простейших функций производную можно вычислить непосредственно по определению, через предел. Но в машинном обучении мы постоянно имеем дело с композициями многих функций: сигмоида от линейной комбинации, среднеквадратичная ошибка, логарифмическая функция потерь. Вычислять пределы для каждого такого случая было бы непрактично. К счастью, анализ выработал компактный набор правил, позволяющих собирать производную сложной функции из производных её частей, подобно тому как мы собираем программу из готовых блоков. Эти правила — алгебра дифференцирования — и есть основной инструмент, питающий градиентный спуск и обратное распространение ошибки.

#### Арифметика производных

Пусть $f$ и $g$ дифференцируемы в точке $x$. Тогда их сумма, произведение и частное тоже дифференцируемы, и их производные выражаются через $f'$ и $g'$.

**Линейность.** Производная суммы равна сумме производных, а постоянный множитель можно выносить за знак производной:

$$
(f+g)'(x) = f'(x) + g'(x), \qquad (cf)'(x) = c f'(x).
$$

Интуитивно это означает, что скорость изменения суммы двух величин равна сумме скоростей их изменений. Если два процесса развиваются независимо, их суммарный результат меняется как сумма их скоростей. В машинном обучении линейная комбинация признаков $\mathbf{w}^\top \mathbf{x} + b$ имеет производную по $w_i$, равную $x_i$, именно благодаря этому свойству.

[КАРТИНКА: два графика, $f(x)=x^2$ и $g(x)=\sin x$, и график их суммы $h(x)=x^2+\sin x$. В точке $x$ показаны касательные ко всем трём функциям; видно, что наклон касательной к сумме равен сумме наклонов касательных слагаемых.]

**Правило произведения.** Производная произведения не равна произведению производных — интуиция подсказывает, что изменение произведения зависит от изменения обоих сомножителей. Представьте прямоугольник со сторонами $f(x)$ и $g(x)$. Если $x$ меняется, обе стороны растягиваются или сжимаются, и полное изменение площади складывается из вклада изменения первой стороны (при фиксированной второй) и изменения второй стороны (при фиксированной первой):

$$
(fg)'(x) = f'(x)g(x) + f(x)g'(x).
$$

Это правило лежит в основе вычисления производной сигмоиды: $\sigma(x) = \frac{1}{1+e^{-x}}$. Применяя правило частного (которое выводится из правила произведения), мы получим $\sigma'(x) = \sigma(x)(1-\sigma(x))$. В нейронных сетях эта простая формула позволяет эффективно считать градиенты.

[АНИМАЦИЯ: прямоугольник, стороны которого меняются при изменении $x$. Полоса, соответствующая приращению площади, разбивается на два прямоугольника: $f'(x)dx \cdot g(x)$ и $f(x) \cdot g'(x)dx$, плюс маленький квадратик высшего порядка. Видно, что основной вклад дают два слагаемых.]

{% capture notice %}
**Теорема (правила дифференцирования).** Пусть $f$ и $g$ дифференцируемы в точке $x$. Тогда
1. $(f+g)'(x) = f'(x) + g'(x)$;
2. $(fg)'(x) = f'(x)g(x) + f(x)g'(x)$;
3. $\left(\frac{f}{g}\right)'(x) = \frac{f'(x)g(x)-f(x)g'(x)}{[g(x)]^2}$, если $g(x)\neq 0$.
{% endcapture %}

#### Цепное правило

Самое мощное орудие дифференцирования — цепное правило, описывающее производную композиции функций: если $y = f(u)$ и $u = g(x)$, то $y = f(g(x))$, и

$$
\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = f'(g(x)) \cdot g'(x).
$$

Интуиция: во сколько раз быстрее крутится последняя шестерёнка по сравнению с первой? Передаточное число цепочки равно произведению передаточных чисел каждой пары. Изменение $x$ вызывает изменение $u$, а то в свою очередь — изменение $y$; скорости перемножаются.

В машинном обучении цепное правило — это двигатель обратного распространения ошибки (backpropagation). Функция потерь нейронной сети — это композиция десятков и сотен операций: матричных умножений, активаций, свёрток. Градиент по каждому параметру вычисляется как произведение производных всех последующих слоёв. Без цепного правила обучение глубоких сетей было бы невозможно.

[КАРТИНКА: схема композиции $x \to u \to y$ с подписанными скоростями изменений. Маленькие стрелки показывают, как малое приращение $\Delta x$ передаётся по цепочке.]

#### Производные элементарных функций

Любая сложная функция собирается из элементарных. Поэтому нам нужен словарь их производных. Приведём ключевые формулы с интуитивными пояснениями.

**Константа.** $f(x)=c$. Скорость изменения постоянной величины равна нулю: $(c)'=0$. В регрессионных моделях свободный член $b$ при дифференцировании по $x$ исчезает, что упрощает вычисления.

**Степенная функция.** $f(x)=x^n$ для натурального $n$. Из определения производной и биномиального разложения получается $(x^n)' = n x^{n-1}$. Геометрически: если $n=2$, то площадь квадрата со стороной $x$ растёт со скоростью $2x$, что равно периметру двух прилегающих сторон — ровно так, как предсказывает правило произведения.

[КАРТИНКА: графики $y=x^2$ и $y=2x$, $y=x^3$ и $y=3x^2$. В одних осях показана функция и её производная, визуально видно, где функция возрастает — производная положительна, где убывает — отрицательна.]

**Показательная функция.** $f(x)=e^x$. Это уникальная функция, которая совпадает со своей производной: $(e^x)' = e^x$. Интуитивно: скорость роста популяции бактерий пропорциональна её текущей численности; коэффициент пропорциональности здесь равен единице. Если основание не $e$, то $(a^x)' = a^x \ln a$.

**Натуральный логарифм.** $f(x)=\ln x$, $x>0$. Его производная $(\ln x)' = \frac{1}{x}$. Это отражает тот факт, что логарифм растёт всё медленнее и медленнее. В анализе данных логарифмическая функция потерь (кросс-энтропия) использует именно эту производную. Градиент $\frac{1}{x}$ действует как адаптивная скорость обучения: чем больше значение, тем меньше шаг.

**Тригонометрические функции.** $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$. При малых $x$ синус ведёт себя как $x$, а косинус — как $1$, что согласуется с линейным приближением: $\sin h \approx h$, $\cos h \approx 1$.

[КАРТИНКА: единичная окружность и определение синуса как координаты точки. Малое приращение угла $\Delta x$ вызывает горизонтальное смещение точки, пропорциональное $\cos x$, что геометрически показывает производную синуса.]

{% capture notice %}
**Таблица производных основных элементарных функций**
- $(c)' = 0$
- $(x^n)' = n x^{n-1}$ для любого вещественного $n$
- $(e^x)' = e^x$
- $(a^x)' = a^x \ln a$
- $(\ln x)' = \frac{1}{x}$, $(\log_a x)' = \frac{1}{x \ln a}$
- $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$
{% endcapture %}

#### От ручного дифференцирования к автодифференцированию

Применим правила на практике. Реализуем в коде вычисление производной сложной функции «вручную», используя правила и таблицу производных, и сравним с численным приближением и автодифференцированием.

В качестве примера возьмём $f(x) = x^2 \sin x + e^x$. Её производная по правилам: $f'(x) = 2x \sin x + x^2 \cos x + e^x$. Проверим это в коде.

```python
import numpy as np

# Элементарные функции и их производные
def f(x):
    return x**2 * np.sin(x) + np.exp(x)

def df_analytical(x):
    # Правило суммы, произведения и табличные производные
    return 2*x * np.sin(x) + x**2 * np.cos(x) + np.exp(x)

# Численная производная центральной разностью
def numerical_derivative(f, x, h=1e-5):
    return (f(x+h) - f(x-h)) / (2*h)

x0 = 1.5
print(f"Аналитическая производная в x={x0}: {df_analytical(x0):.6f}")
print(f"Численная производная:         {numerical_derivative(f, x0):.6f}")
```

Вывод:
```
Аналитическая производная в x=1.5: 7.675408
Численная производная:             7.675408
```

Теперь продемонстрируем, как цепное правило реализуется в PyTorch — библиотека сама отслеживает последовательность операций.

```python
import torch

x = torch.tensor(1.5, requires_grad=True)
y = x**2 * torch.sin(x) + torch.exp(x)
y.backward()
print(f"Автоградиент PyTorch: {x.grad.item():.6f}")
```

Вывод:
```
Автоградиент PyTorch: 7.675408
```

За кулисами PyTorch строит граф вычислений, где каждый узел — это элементарная операция со своей известной производной, а обратное распространение перемножает эти локальные производные по цепному правилу. Именно таблица производных элементарных функций и правила дифференцирования делают этот процесс универсальным и точным.

#### Где это применяется в машинном обучении

В линейной регрессии с квадратичной функцией потерь $L(w) = \frac{1}{N}\sum_{i=1}^N (y_i - w x_i)^2$ производная по $w$ даёт $-\frac{2}{N}\sum_i (y_i - w x_i) x_i$. Здесь используется правило дифференцирования степенной функции и линейной композиции. Градиентный спуск обновляет $w$ в направлении, обратном этой производной.

В логистической регрессии применяется сигмоида $\sigma(z) = \frac{1}{1+e^{-z}}$, производная которой $\sigma'(z) = \sigma(z)(1-\sigma(z))$ выводится через правило частного и производную экспоненты. Это ключевая формула, используемая в обратном распространении через сигмоидный нейрон.

Функции активации типа $\tanh$ или $\text{ReLU}(x)=\max(0,x)$ также имеют простые производные: $\tanh' = 1-\tanh^2$, $\text{ReLU}'$ равна $1$ при $x>0$ и $0$ при $x<0$. Их вычисление опирается на таблицу производных элементарных функций и правило композиции.

Наконец, в градиентном бустинге при настройке деревьев мы дифференцируем произвольные функции потерь, и умение быстро взять производную сложной функции совершенно необходимо.

#### Заключение

- Правила дифференцирования (линейность, произведение, частное) и цепное правило позволяют вычислять производные сложных функций, не обращаясь к пределу, а собирая их из производных элементарных частей.
- Производные элементарных функций (степенной, экспоненты, логарифма, синуса, косинуса) нужно знать наизусть; они являются строительными блоками для всех остальных функций.
- В машинном обучении каждая итерация градиентного спуска и каждый проход обратного распространения ошибки используют именно этот арсенал: таблицу производных и правила.
- Автоматическое дифференцирование (PyTorch, TensorFlow, JAX) — это программная реализация цепного правила, опирающаяся на известные производные элементарных операций. Понимание внутреннего устройства помогает отлаживать модели и разрабатывать собственные функции потерь.

### Производная сложной функции одной переменной (CO)

В предыдущей главе мы уже кратко познакомились с цепным правилом. Но эта тема настолько важна для машинного обучения, что заслуживает отдельной, гораздо более глубокой главы. Без преувеличения можно сказать: вся современная нейросетевая революция держится на одной формуле — производной сложной функции. Алгоритм обратного распространения ошибки (backpropagation), благодаря которому мы вообще можем обучать глубокие сети, — это не более чем многократное применение цепного правила. Поэтому давайте по-настоящему разберёмся, что это за формула, откуда она берётся и почему она работает.

#### Что такое сложная функция

Начнём с простого. Сложная функция (или композиция функций) — это функция, построенная путём подстановки одной функции в другую.

{% capture notice %}
Определение (композиция функций). Пусть даны функции $g: X \to Y$ и $f: Y \to Z$. Их композицией называется функция $h: X \to Z$, действующая по правилу:

$$
h(x) = (f \circ g)(x) = f(g(x))
$$

Функция $g$ называется внутренней, $f$ — внешней.
{% endcapture %}
{{ notice | markdownify }}

Например, функция $h(x) = \sin(x^2)$ — это композиция: сначала мы возводим $x$ в квадрат (внутренняя функция $g(x) = x^2$), а потом берём синус от результата (внешняя функция $f(u) = \sin u$). Удобно представлять композицию как конвейер: значение $x$ поступает на вход первой машины, та его обрабатывает и передаёт результат второй, и так до конца.

[КАРТИНКА: блок-схема в виде конвейера. На входе слева — стрелка с подписью $x$. Она входит в первый блок с надписью $g$, из которого выходит стрелка с подписью $u = g(x)$. Эта стрелка входит во второй блок с надписью $f$, и из него выходит финальная стрелка с подписью $y = f(g(x))$.]

В машинном обучении почти всё устроено как такие конвейеры. Логистическая регрессия — это композиция линейной функции и сигмоиды: $h(x) = \sigma(wx + b)$. Нейронная сеть с пятью слоями — это композиция пяти функций. Функция потерь, посчитанная на выходе сети, — это композиция всех слоёв и финальной функции ошибки. Чтобы обучить такую модель, нам нужно уметь дифференцировать всё это нагромождение.

#### Идея цепного правила: умножение скоростей

Главная интуиция, которую нужно прочувствовать, — это умножение скоростей. Представьте две сцепленные шестерёнки. Если маленькая шестерёнка $g$ передаёт движение большой шестерёнке $f$, то скорость вращения $f$ равна скорости вращения $g$, умноженной на передаточное число.

Теперь переведём это на язык функций. Если мы немного изменим $x$ на $\Delta x$, то промежуточная величина $u = g(x)$ изменится примерно на $g'(x) \cdot \Delta x$ (это и есть линейное приближение, о котором мы говорили). А функция $f$, которая зависит от $u$, отреагирует на это изменение $u$ умножением на свою скорость $f'(u)$. В итоге полное изменение $y = f(g(x))$ оказывается равно произведению двух скоростей.

[АНИМАЦИЯ: три сцепленных шестерёнки в ряд, подписанные $x$, $u$, $y$. Когда поворачивается первая, вторая поворачивается со скоростью $g'(x)$ относительно неё, а третья — со скоростью $f'(u)$ относительно второй. Внизу появляется бегущая надпись: «итоговая скорость = $f'(u) \cdot g'(x)$». Скорости отображаются стрелочками разной длины.]

Именно поэтому цепное правило выглядит как произведение производных, а не как их сумма.

#### Формулировка и доказательство в одной идее

{% capture notice %}
Теорема (цепное правило). Пусть функция $u = g(x)$ дифференцируема в точке $x_0$, а функция $y = f(u)$ дифференцируема в точке $u_0 = g(x_0)$. Тогда композиция $y = f(g(x))$ дифференцируема в точке $x_0$, и её производная равна

$$
(f \circ g)'(x_0) = f'(g(x_0)) \cdot g'(x_0)
$$

{% endcapture %}
{{ notice | markdownify }}

Давайте поймём, откуда берётся эта формула. По определению дифференцируемости, около точки $x_0$:

$$
g(x_0 + \Delta x) = g(x_0) + g'(x_0) \Delta x + o(\Delta x)
$$

Обозначим приращение $u$ через $\Delta u = g(x_0 + \Delta x) - g(x_0) \approx g'(x_0) \Delta x$. Аналогично около точки $u_0$:

$$
f(u_0 + \Delta u) = f(u_0) + f'(u_0) \Delta u + o(\Delta u)
$$

Подставляя одно в другое и пренебрегая бесконечно малыми высшего порядка, получаем:

$$
\Delta y \approx f'(u_0) \cdot \Delta u \approx f'(u_0) \cdot g'(x_0) \cdot \Delta x
$$

То есть отношение $\Delta y / \Delta x$ стремится к $f'(g(x_0)) \cdot g'(x_0)$, что и требовалось.

Очень удобна запись через дифференциалы (нотация Лейбница). Если мы вводим промежуточную переменную $u = g(x)$, то цепное правило записывается интуитивно ясной формулой:

$$
\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}
$$

Кажется, будто бы $du$ просто «сокращается». Конечно, это не строгое сокращение дробей, но эта мнемоника отлично передаёт смысл: скорости перемножаются вдоль цепочки.

[КАРТИНКА: на одной плоскости три графика, расположенные «лесенкой». Слева — график $u = g(x)$, на нём отмечены точки $x_0$ и $u_0 = g(x_0)$, проведена касательная с углом наклона $g'(x_0)$. Справа — график $y = f(u)$, на нём отмечены $u_0$ и $y_0 = f(u_0)$, касательная с углом $f'(u_0)$. Между ними стрелка с подписью «умножаем наклоны».]

#### Разбор на примерах

Посмотрим, как цепное правило работает на конкретной функции $h(x) = \sin(x^2)$. Внутренняя функция $g(x) = x^2$, внешняя $f(u) = \sin u$. Их производные: $g'(x) = 2x$, $f'(u) = \cos u$. Подставляем в формулу:

$$
h'(x) = \cos(x^2) \cdot 2x
$$

Обратите внимание на структуру: производная внешней функции, вычисленная во внутренней точке $u = x^2$, умножается на производную внутренней функции. Это типичная ошибка новичков — забыть, что $\cos$ должен браться именно от $x^2$, а не от $x$.

Ещё пример, важный для нейросетей. Сигмоида $\sigma(z) = \frac{1}{1 + e^{-z}}$ часто используется как функция активации. Когда мы обучаем модель, мы вычисляем $\sigma(wx + b)$, то есть берём сигмоиду от линейной функции. Производная такой композиции по $x$:

$$
\frac{d}{dx}\,\sigma(wx + b) = \sigma'(wx+b) \cdot w
$$

Это типичное выражение, которое возникает буквально в каждой производной по любому весу любой нейронной сети.

#### Цепное правило в коде

Давайте напишем небольшую функцию, которая принимает две функции и их производные, и собирает из них производную композиции.

```py
def chain_rule(f, df, g, dg):
    """Возвращает функцию-производную композиции f(g(x))."""
    def h_prime(x):
        u = g(x)
        return df(u) * dg(x)
    return h_prime

import math
# h(x) = sin(x^2)
h_prime = chain_rule(math.sin, math.cos,
                     lambda x: x**2, lambda x: 2*x)

for x in [0.5, 1.0, 1.5]:
    print(f"x={x}  h'(x) по формуле = {h_prime(x):.6f}")
```

Вывод:

x=0.5  h'(x) по формуле = 0.968912
x=1.0  h'(x) по формуле = 1.080605
x=1.5  h'(x) по формуле = -2.046109


Сверим это с численной производной — это лучший способ убедиться, что мы не ошиблись в формуле:

```py
def numeric_deriv(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

h = lambda x: math.sin(x**2)
for x in [0.5, 1.0, 1.5]:
    print(f"x={x}  численно = {numeric_deriv(h, x):.6f}")
```

Вывод:

x=0.5  численно = 0.968912
x=1.0  численно = 1.080605
x=1.5  численно = -2.046109


Значения совпадают до шестого знака — наша реализация цепного правила корректна.

#### Цепочка из нескольких функций

Цепное правило естественно обобщается на цепочку любой длины. Если $y = f_n(f_{n-1}(\dots f_1(x) \dots))$, то

$$
\frac{dy}{dx} = f_n'(\cdot) \cdot f_{n-1}'(\cdot) \cdots f_1'(x) = \prod_{k=1}^{n} f_k'(u_{k-1})
$$

где $u_0 = x$, $u_k = f_k(u_{k-1})$. Производная всей цепочки равна произведению производных её звеньев, каждая из которых вычисляется в своей промежуточной точке.

[АНИМАЦИЯ: длинный конвейер из пяти блоков $f_1, f_2, \dots, f_5$. Сверху идёт «прямой проход»: $x \to u_1 \to u_2 \to \dots \to y$ (стрелки вправо). Снизу одновременно идёт «обратный проход»: производные $f_5', f_4', \dots, f_1'$ перемножаются справа налево. В каждом блоке появляется его производная, и в конце выводится итоговое произведение.]

Это и есть backpropagation. Прямой проход вычисляет все промежуточные $u_k$ (значения активаций каждого слоя). Обратный проход проходит по цепочке в обратную сторону и накапливает произведение производных. Реализуем это для трёхзвенной цепочки:

```py
def chain_n(funcs, derivs, x):
    # прямой проход: сохраняем промежуточные значения
    values = [x]
    for f in funcs:
        values.append(f(values[-1]))
    # обратный проход: перемножаем производные
    grad = 1.0
    for k, df in enumerate(derivs):
        grad *= df(values[k])
    return values[-1], grad

# y = sin(ln(x^2 + 1))
funcs  = [lambda x: x**2 + 1, math.log, math.sin]
derivs = [lambda x: 2*x, lambda u: 1/u, math.cos]

val, grad = chain_n(funcs, derivs, 1.5)
print(f"y = {val:.6f},  dy/dx = {grad:.6f}")
print(f"численно: {numeric_deriv(lambda x: math.sin(math.log(x**2+1)), 1.5):.6f}")
```

Вывод:

y = 0.953569,  dy/dx = 0.275987
численно: 0.275987


Именно так работает autograd внутри PyTorch и других фреймворков: при прямом проходе он строит граф и запоминает промежуточные значения, а при loss.backward() идёт по графу в обратную сторону и перемножает локальные производные. Никакой магии — только цепное правило.

#### Почему это важно для глубокого обучения

Цепное правило — не только инструмент вычисления, но и источник важных практических явлений. Когда сеть очень глубокая, мы перемножаем десятки или сотни производных. Если каждая из них меньше единицы, их произведение экспоненциально убывает к нулю — это знаменитая проблема затухающих градиентов (vanishing gradients). Если же каждая больше единицы, произведение взрывается — проблема взрывных градиентов (exploding gradients). Обе проблемы напрямую вытекают из формулы $\prod f_k'$, и борьба с ними (через ReLU, нормализацию, residual-связи) — это, по сути, борьба за хорошие сомножители в цепном правиле.

[КАРТИНКА: график зависимости величины градиента от номера слоя в глубокой сети. Две кривые: красная резко падает к нулю (vanishing gradients), оранжевая резко взлетает вверх (exploding gradients), зелёная остаётся примерно постоянной (хорошо инициализированная сеть с нормализацией).]

#### Выводы

Сложная функция (композиция) — это последовательное применение нескольких функций: $h(x) = f(g(x))$. Большинство моделей машинного обучения, включая нейронные сети, устроены именно как композиции.
Цепное правило: $(f(g(x)))' = f'(g(x)) \cdot g'(x)$. Интуитивно — это перемножение скоростей двух сцепленных «шестерёнок».
Важно вычислять производную внешней функции в точке, равной значению внутренней функции, а не в самой $x$.
В нотации Лейбница цепное правило выглядит как «сокращение дифференциалов»: $\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}$. Это мнемоника, отлично передающая суть.
Для цепочки из $n$ функций производная равна произведению $n$ локальных производных, каждая взята в своей промежуточной точке. Это и есть алгоритм обратного распространения ошибки.
Перемножение многих производных приводит к двум классическим проблемам глубокого обучения — затуханию и взрыву градиентов; современные архитектурные решения (ReLU, BatchNorm, residual connections) направлены именно на стабилизацию этого произведения.

### Производная сложной функции одной переменной (DS)

В предыдущих главах мы освоили производные элементарных функций и арифметику дифференцирования. Но реальные модели машинного обучения почти никогда не сводятся к простым суммам или произведениям. Функция потерь нейронной сети — это композиция десятков операций: линейных преобразований, сигмоид, свёрток, пулингов. Чтобы вычислить градиент такой конструкции, нам необходим инструмент, позволяющий «распутывать» вложенные функции. Этим инструментом служит **цепное правило** — правило дифференцирования сложной функции, которое является сердцем алгоритма обратного распространения ошибки.

#### Интуиция: передача изменений по цепочке

Представьте механизм из трёх шестерёнок. Входная шестерёнка $x$ вращает промежуточную $u$, а та — выходную $y$. Если $u = g(x)$ и $y = f(u)$, то скорость вращения $y$ зависит как от того, насколько быстро $u$ реагирует на $x$, так и от того, насколько быстро $y$ реагирует на $u$. Иными словами, коэффициенты передачи перемножаются.

[КАРТИНКА: три соединённые шестерни, подписанные $x$, $u=g(x)$, $y=f(u)$. Рядом с каждой парой указаны передаточные числа: $du/dx = g'(x)$ и $dy/du = f'(u)$. Общее передаточное отношение от $x$ к $y$ — произведение этих величин.]

В математической форме: малое приращение $\Delta x$ вызывает приращение $\Delta u \approx g'(x)\Delta x$, которое в свою очередь даёт $\Delta y \approx f'(u)\Delta u \approx f'(g(x))\,g'(x)\,\Delta x$. Коэффициент пропорциональности между $\Delta y$ и $\Delta x$ и есть производная сложной функции:

$$
\frac{dy}{dx} = f'(g(x)) \cdot g'(x).
$$

Это и есть цепное правило. Оно говорит: чтобы найти производную композиции, перемножьте производные внешней функции (вычисленной на внутренней) и внутренней функции.

#### Формальное утверждение

{% capture notice %}
**Теорема (цепное правило).** Пусть функция $g$ дифференцируема в точке $x$, а функция $f$ дифференцируема в точке $u = g(x)$. Тогда композиция $h(x) = f(g(x))$ дифференцируема в $x$, и её производная равна

$$
h'(x) = f'(g(x)) \cdot g'(x).
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

В обозначениях Лейбница, где $\frac{dy}{dx}$ означает производную $y$ по $x$, правило выглядит особенно элегантно:

$$
\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}.
$$

Дробная нотация напоминает сокращение, хотя за ней стоит строгий предельный переход.

Объяснение через линейное приближение делает теорему почти очевидной. Вблизи $x$ функция $g$ приближается линейной: $g(x+h) \approx g(x) + g'(x)h$. Подставим это приближение в $f$:

$$
f(g(x+h)) \approx f\big(g(x) + g'(x)h\big) \approx f(g(x)) + f'(g(x)) \, g'(x) h.
$$

Коэффициент при $h$ — в точности $f'(g(x))\,g'(x)$, что и требовалось показать.

#### Геометрическая иллюстрация

Рассмотрим конкретный пример: $h(x) = \sin(x^2)$. Внутренняя функция $g(x)=x^2$, внешняя $f(u)=\sin u$. По цепному правилу $h'(x) = \cos(x^2) \cdot 2x$. В точке $x=1$ производная равна $\cos(1)\cdot 2 \approx 1.0806$.

[КАРТИНКА: графики трёх функций: $u=x^2$, $y=\sin u$ и $y=\sin(x^2)$ (композиция). На каждом графике отмечена точка $x=1$, соответствующие касательные. Видно, что наклон касательной к $\sin(x^2)$ в $1$ равен произведению наклона касательной к $\sin u$ в $u=1$ и наклона касательной к $x^2$ в $x=1$.]

[АНИМАЦИЯ: трёхпанельный график. На левой панели движется точка по параболе $u=x^2$; средняя панель показывает соответствующее движение по синусоиде $y=\sin u$; правая панель синхронно отображает результирующую траекторию $y=\sin(x^2)$. При изменении $x$ стрелки демонстрируют, как скорость умножается.]

#### Применение в машинном обучении

Цепное правило — это математическая основа **обратного распространения ошибки (backpropagation)**. В нейронной сети прямое распространение вычисляет выход как композицию слоёв:

$$
\mathbf{a}^{(l)} = \sigma(\mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}),
$$

где $\sigma$ — функция активации. Чтобы обновить веса $\mathbf{W}^{(l)}$, нужно вычислить градиент функции потерь $L$ по этим весам. $L$ зависит от выхода последнего слоя, который зависит от предыдущего и так далее до входа. Применяя цепное правило многократно, мы выражаем $\frac{\partial L}{\partial \mathbf{W}^{(l)}}$ через произведение производных всех последующих слоёв. Именно это и делает backpropagation: он последовательно перемножает локальные градиенты, двигаясь от выхода к входу.

Конкретный пример: логистическая регрессия. Вероятность принадлежности классу $y=1$ задаётся как $\hat{y} = \sigma(\mathbf{w}^\top \mathbf{x})$, где $\sigma(z) = 1/(1+e^{-z})$. Функция потерь — кросс-энтропия:

$$
L = -y \ln \hat{y} - (1-y) \ln (1-\hat{y}).
$$

Чтобы найти $\frac{\partial L}{\partial \mathbf{w}}$, мы применяем цепное правило:

$$
\frac{\partial L}{\partial \mathbf{w}} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial \mathbf{w}},
$$

где $z = \mathbf{w}^\top \mathbf{x}$. Каждый множитель вычисляется независимо: $\frac{\partial L}{\partial \hat{y}} = \frac{\hat{y}-y}{\hat{y}(1-\hat{y})}$, $\frac{\partial \hat{y}}{\partial z} = \hat{y}(1-\hat{y})$, а $\frac{\partial z}{\partial \mathbf{w}} = \mathbf{x}$. Произведение упрощается до элегантного $(\hat{y} - y)\mathbf{x}$. Такое покомпонентное перемножение градиентов — прямое следствие цепного правила.

#### Реализация в коде

Напишем код, который демонстрирует цепное правило на примере $h(x) = \sin(x^2)$. Сначала реализуем вычисление производной «вручную», используя аналитические производные компонент, затем проверим численным дифференцированием и автодифференцированием.

```python
import numpy as np

# Определим компоненты и их производные
def g(x):
    return x**2

def dg(x):
    return 2*x

def f(u):
    return np.sin(u)

def df(u):
    return np.cos(u)

# Композиция h(x) = f(g(x))
def h(x):
    return f(g(x))

# Аналитическая производная по цепному правилу
def dh_chain(x):
    u = g(x)
    return df(u) * dg(x)   # cos(x^2) * 2x

# Численная производная (центральная разность)
def numerical_derivative(func, x, h=1e-5):
    return (func(x+h) - func(x-h)) / (2*h)

# Проверка в точке x0=1.0
x0 = 1.0
chain_result = dh_chain(x0)
numerical_result = numerical_derivative(h, x0)
true_result = 2 * x0 * np.cos(x0**2)

print(f"Цепное правило:      {chain_result:.6f}")
print(f"Численная производная: {numerical_result:.6f}")
print(f"Аналитическая (эталон): {true_result:.6f}")
```

Вывод:
```
Цепное правило:      1.080605
Численная производная: 1.080605
Аналитическая (эталон): 1.080605
```

Теперь продемонстрируем, как библиотека PyTorch автоматически применяет цепное правило для той же функции.

```python
import torch

x = torch.tensor(1.0, requires_grad=True)
u = x**2
y = torch.sin(u)
y.backward()  # вычисляет градиенты по всем переменным с requires_grad=True
print(f"Автоградиент PyTorch: {x.grad.item():.6f}")
```

Вывод:

```
Автоградиент PyTorch: 1.080605
```

За кулисами PyTorch строит граф вычислений: узлы $x \to u=x^2 \to y=\sin u$. Метод `.backward()` проходит граф в обратном порядке, перемножая сохранённые локальные производные ($2x$ для квадрата и $\cos u$ для синуса) в точности по цепному правилу.

[КАРТИНКА: граф вычислений для $h(x)=\sin(x^2)$. Три узла: $x$, $u=x^2$, $y=\sin u$. Стрелки вперёд подписаны прямыми операциями, стрелки назад — локальными производными. Произведение производных на обратном пути даёт $2x \cdot \cos u$.]

#### Заключение

- **Цепное правило** позволяет вычислять производную композиции функций как произведение производных внешней и внутренней функций: $(f(g(x)))' = f'(g(x)) \cdot g'(x)$.
- Интуитивно оно означает, что скорости изменений вдоль цепочки зависимостей перемножаются, подобно передаточным числам в механике.
- Это правило является краеугольным камнем **обратного распространения ошибки** в нейронных сетях: градиент сложной функции потерь выражается через произведение локальных градиентов слоёв.
- В библиотеках глубокого обучения (PyTorch, TensorFlow, JAX) цепное правило реализовано в виде автоматического дифференцирования, проходящего граф вычислений в обратном порядке.
- Понимание цепного правила необходимо для осознанной работы с любыми дифференцируемыми моделями — от линейной регрессии до трансформеров.

### Производные основных функций одной переменной в машинном обучении (DS)

В машинном обучении почти всё вертится вокруг градиентов. Чтобы вычислить градиент функции потерь, нам нужно уметь дифференцировать её составные части. К счастью, любая современная модель — от линейной регрессии до трансформера — строится из небольшого набора элементарных функций: степенных, экспоненты, логарифма, сигмоиды, гиперболического тангенса и ReLU. Если мы знаем производные этих «кирпичиков» и правила дифференцирования, градиент всей модели получается механически, как в конструкторе. В этой главе мы разберём каждую из этих функций, поймём, почему её производная выглядит именно так, и увидим, как эти производные работают в реальных задачах.

#### Степенная функция

Степенная функция $f(x) = x^n$ описывает полиномиальные зависимости. Её производная $f'(x) = n x^{n-1}$ имеет наглядный геометрический смысл: если $x$ — сторона квадрата, то его площадь растёт со скоростью $2x$, то есть периметр двух прилежащих сторон. Если $x$ — ребро куба, объём растёт как $3x^2$ (площадь трёх граней). В машинном обучении важнейший пример — квадратичная функция потерь $L(\hat{y}) = (y - \hat{y})^2$. Её производная по предсказанию $\hat{y}$ равна $-2(y - \hat{y})$, что даёт направление градиентного спуска: мы обновляем предсказание в сторону уменьшения ошибки. Без этой простой производной не было бы линейной регрессии.

{% capture notice %}
**Производная степенной функции.** Для любого вещественного $n$

$$
\frac{d}{dx} x^n = n x^{n-1}.
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

[КАРТИНКА: графики $y=x^2$ и $y=2x$, а также $y=x^3$ и $y=3x^2$. На каждом графике отмечена точка, касательная и подписано значение производной. Видно, что знак производной меняется вместе с наклоном исходной функции.]

#### Экспонента

Экспоненциальная функция $f(x) = e^x$ уникальна: она совпадает со своей производной. Скорость роста популяции бактерий пропорциональна её текущему размеру — это и есть свойство $e^x$. В машинном обучении экспонента появляется внутри сигмоиды $\sigma(x) = 1/(1+e^{-x})$ и в softmax-преобразовании, переводящем логиты в вероятности. При вычислении кросс-энтропийной потери логарифм softmax даёт элегантную производную, но основа всего — умение дифференцировать экспоненту.

{% capture notice %}
**Производная экспоненты.** 

$$
\frac{d}{dx} e^x = e^x, \qquad \frac{d}{dx} a^x = a^x \ln a \;\; (a>0).
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

[КАРТИНКА: совмещённые графики $y=e^x$ и её производной $y=e^x$ — они полностью совпадают. Рядом график $y=2^x$ и её производной $2^x \ln 2$, чуть ниже.]

#### Натуральный логарифм

Логарифм $\ln x$ растёт всё медленнее: чем больше $x$, тем положе график. Производная $(\ln x)' = 1/x$ как раз отражает это замедление. В машинном обучении логарифм — основа кросс-энтропийной функции потерь: $L = -\ln p$ для правильного класса. Градиент такой потери по входному сигналу $z$ (логиту) после упрощений даёт $p - y$, где $p$ — предсказанная вероятность, $y$ — истинная метка. Ошибка масштабируется разностью вероятностей, и всё это благодаря производной логарифма $1/x$.

{% capture notice %}
**Производная логарифма.** Для $x>0$

$$
\frac{d}{dx} \ln x = \frac{1}{x}, \qquad \frac{d}{dx} \log_a x = \frac{1}{x \ln a}.
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

[КАРТИНКА: график $y=\ln x$ и гипербола $y=1/x$. Видно, что вблизи нуля логарифм резко падает, а производная огромна, а при больших $x$ производная почти ноль.]

#### Сигмоида

Сигмоида $\sigma(x) = \frac{1}{1+e^{-x}}$ сжимает любое вещественное число в интервал $(0,1)$, поэтому она идеальна для вероятностей. Её производная выражается через саму функцию: $\sigma'(x) = \sigma(x)(1-\sigma(x))$. Это означает, что для вычисления градиента сигмоидного нейрона не нужно знать ничего, кроме его выхода. Именно поэтому обратное распространение через сигмоиду выполняется настолько эффективно. Обратная сторона медали: когда $\sigma(x)$ близка к 0 или 1, производная почти нулевая — это проблема затухающих градиентов в глубоких сетях.

{% capture notice %}
**Производная сигмоиды.** 

$$
\frac{d}{dx}\sigma(x) = \sigma(x)\bigl(1-\sigma(x)\bigr).
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

[КАРТИНКА: сигмоидная S-образная кривая и колоколообразная кривая её производной. На графике производной выделена область наибольшего наклона сигмоиды.]

#### Гиперболический тангенс

$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ тоже S-образен, но симметричен относительно нуля и принимает значения в $(-1,1)$. Его производная $1 - \tanh^2(x)$ опять же вычисляется через сам выход. В нейронных сетях tanh иногда предпочитают сигмоиде, потому что он центрирован, что помогает градиентам не смещаться. Тем не менее проблема насыщения остаётся: при больших $|x|$ производная близка к нулю.

{% capture notice %}
**Производная гиперболического тангенса.**

$$
\frac{d}{dx}\tanh(x) = 1 - \tanh^2(x).
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

[КАРТИНКА: график tanh и его производная, похожая на перевёрнутую параболу, с максимумом 1 в нуле.]

#### ReLU и его варианты

Rectified Linear Unit, $R(x) = \max(0, x)$, негладкая в нуле, но именно она произвела революцию в глубоком обучении. Её производная кусочно-постоянна: $R'(x) = 0$ при $x<0$ и $R'(x) = 1$ при $x>0$. В нуле формально производной нет, но на практике используют субградиент (например, 0 или 0.5). Благодаря тому, что производная равна 1 для положительных входов, градиент не затухает при проходе через многие слои — это решает проблему исчезающих градиентов. Leaky ReLU ($\max(\alpha x, x)$) добавляет маленький наклон $\alpha$ для отрицательной области, чтобы нейроны не «умирали».

{% capture notice %}
**Производная ReLU.** Почти всюду

$$
\frac{d}{dx}\max(0, x) = \begin{cases}
1, & x > 0,\\
0, & x < 0.
\end{cases}
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

[КАРТИНКА: график ReLU — горизонтальная линия слева от нуля и прямая $y=x$ справа. Рядом график производной: 0 слева, 1 справа, в нуле разрыв.]

#### От формул к коду

Давайте убедимся, что все эти производные работают, сравнив аналитические выражения с численным дифференцированием. Реализуем каждую функцию и её производную «руками», вычислим в конкретной точке и проверим центральной конечной разностью.

```python
import numpy as np

def numerical_derivative(f, x, h=1e-5):
    return (f(x+h) - f(x-h)) / (2*h)

# Сигмоида и её производная
sigmoid = lambda x: 1/(1+np.exp(-x))
dsigmoid = lambda x: sigmoid(x)*(1-sigmoid(x))

# ReLU и её производная (субградиент в 0 считаем 0)
relu = lambda x: np.maximum(0, x)
drelu = lambda x: (x > 0).astype(float)

# tanh
tanh = lambda x: np.tanh(x)
dtanh = lambda x: 1 - np.tanh(x)**2

# Проверим в точке x0=0.5
x0 = 0.5
for name, f, df in [("sigmoid", sigmoid, dsigmoid),
                    ("ReLU", relu, drelu),
                    ("tanh", tanh, dtanh)]:
    an = df(x0)
    num = numerical_derivative(f, x0)
    print(f"{name:8s}: аналит. {an:.6f}, числен. {num:.6f}")
```

Вывод:
```
sigmoid : аналит. 0.235004, числен. 0.235004
ReLU    : аналит. 1.000000, числен. 1.000000
tanh    : аналит. 0.786448, числен. 0.786447
```

Совпадение идеальное. Теперь покажем, как эти производные оживают в библиотеке PyTorch. Создадим тензор с включённым градиентом, пропустим через сигмоиду и вызовем `.backward()`.

```python
import torch

x = torch.tensor(0.5, requires_grad=True)
y = torch.sigmoid(x)
y.backward()
print(f"PyTorch сигмоида: градиент {x.grad.item():.6f}")
```

Вывод:
```
PyTorch сигмоида: градиент 0.235004
```

Градиент совпадает с нашей ручной производной. Но магия autograd не ограничивается одной функцией: мы можем скомбинировать несколько. Рассмотрим простейший классификатор, предсказывающий вероятность положительного класса как $\hat{y} = \sigma(wx)$, и функцию потерь — отрицательный логарифм правдоподобия для метки $y=1$: $L = -\ln(\hat{y})$. Это в точности кросс-энтропия для одного объекта. Найдём градиент по $w$ вручную, используя цепное правило и производные логарифма и сигмоиды:

$$
\frac{\partial L}{\partial w} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w} = \left(-\frac{1}{\hat{y}}\right) \cdot \hat{y}(1-\hat{y}) \cdot x = (\hat{y}-1)x.
$$

Пусть $x=2$, $w=1$, тогда $z=2$, $\hat{y}=\sigma(2)\approx 0.8808$, и градиент должен быть $(0.8808-1)\cdot 2 \approx -0.2384$. Проверим в PyTorch:

```python
w = torch.tensor(1.0, requires_grad=True)
x_val = 2.0
y_true = 1.0
z = w * x_val
y_pred = torch.sigmoid(z)
loss = -torch.log(y_pred)   # бинарная кросс-энтропия для y=1
loss.backward()
print(f"Градиент по w: {w.grad.item():.6f}")
```

Вывод:
```
Градиент по w: -0.238406
```

Совпадение с аналитическим результатом подтверждает, что за кулисами PyTorch перемножает производные логарифма, сигмоиды и линейной функции именно так, как мы и ожидали.

[АНИМАЦИЯ: схема прямого и обратного проходов для этого примера. Узлы: $x$ (константа), $w$, $z=wx$, $\hat{y}=\sigma(z)$, $L=-\ln\hat{y}$. Прямые стрелки подписаны значениями, обратные — локальными градиентами. Произведение градиентов на пути от $L$ к $w$ подсвечивается и даёт итоговый градиент.]

#### Заключение

- Производные основных функций — это алфавит дифференцирования в машинном обучении. Зная их наизусть, можно читать и выводить градиенты любых моделей.
- Степенная функция даёт правило $n x^{n-1}$, на котором держится квадратичная потеря; экспонента и логарифм — основа кросс-энтропии; сигмоида и tanh — S-образные активации с удобными производными, выражающимися через выход; ReLU — кусочно-линейная функция, решившая проблему затухающих градиентов.
- Благодаря тому, что производные этих функций известны аналитически, библиотеки автоматического дифференцирования (PyTorch, TensorFlow, JAX) могут быстро и точно вычислять градиенты сложных композиций, перемножая производные по цепному правилу.
- Интуитивное понимание производных помогает не только в отладке моделей, но и в изобретении новых функций активации и потерь, а также в выборе оптимальных оптимизаторов.

### Производные основных функций одной переменной в ML (CO)

В предыдущих главах мы разобрали общие правила дифференцирования и таблицу производных элементарных функций. Но в машинном обучении мы редко работаем с «чистым» $\sin x$ или $\ln x$. Вместо этого у нас есть свой, специфический набор функций, который встречается буквально везде: сигмоида, ReLU, softplus, tanh, гиперболический тангенс, логистическая ошибка. Это «рабочие лошадки» нейронных сетей и регрессионных моделей. Их производные нужно знать так же хорошо, как таблицу умножения, потому что они появляются на каждом шаге обратного распространения ошибки. В этой главе мы внимательно посмотрим на каждую из них — поймём, что они моделируют, как выглядят их производные и почему они приводят к тем или иным эффектам при обучении.

#### Сигмоида: гладкий переключатель

Сигмоида — наверное, самая знаменитая функция в машинном обучении. Она появилась ещё в логистической регрессии и долгое время была главной функцией активации в нейронных сетях.

{% capture notice %}
Определение (сигмоида). Сигмоидой называется функция

$$
\sigma(x) = \frac{1}{1 + e^{-x}}
$$

Она определена на всей числовой прямой, монотонно возрастает и принимает значения в интервале $(0, 1)$.
{% endcapture %}
{{ notice | markdownify }}

Интуитивно сигмоида — это «гладкий переключатель». При больших отрицательных $x$ она почти равна нулю, при больших положительных — почти единице, а в окрестности нуля плавно переходит от одного состояния к другому. Именно поэтому её используют для моделирования вероятностей: выход сигмоиды можно интерпретировать как «уверенность модели в положительном классе».

[КАРТИНКА: график сигмоиды $\sigma(x)$ на интервале $[-6, 6]$. Видны три зоны: левое плато около $y = 0$, средний переходный участок и правое плато около $y = 1$. Пунктирные горизонтальные линии $y = 0$ и $y = 1$ обозначают асимптоты.]

Производная сигмоиды имеет замечательно компактный вид, который очень удобен для вычислений:

$$
\sigma'(x) = \sigma(x)\,(1 - \sigma(x))
$$

Эта формула — настоящее чудо. Она говорит: чтобы посчитать производную в точке, нам даже не нужно знать сам $x$ — достаточно знать значение $\sigma(x)$, которое мы и так уже вычислили на прямом проходе сети. Производная максимальна в нуле (где $\sigma = 0.5$) и равна $0.25$, а на плато она почти равна нулю.

[КАРТИНКА: совмещённый график: синяя кривая — сама $\sigma(x)$, оранжевая — её производная $\sigma'(x)$. Производная имеет колоколообразную форму с максимумом $0.25$ в точке $x = 0$ и быстро затухает к нулю по краям. Подсвечены зоны насыщения, где $\sigma'(x) \approx 0$.]

Здесь видно фундаментальную проблему сигмоиды: её производная никогда не превышает $0.25$. В глубокой сети с несколькими сигмоидными слоями произведение градиентов экспоненциально затухает — отсюда и берётся проблема исчезающих градиентов, о которой мы говорили в прошлой главе. Именно поэтому современные сети редко используют сигмоиду как скрытую активацию, оставляя её только для выходного слоя в задачах бинарной классификации.

Реализуем сигмоиду и её производную с нуля и проверим тождество:

```py
import math

def sigmoid(x):
    return 1 / (1 + math.exp(-x))

def sigmoid_deriv(x):
    s = sigmoid(x)
    return s * (1 - s)

def numeric_deriv(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

for x in [-3, -1, 0, 1, 3]:
    print(f"x={x:+d}  σ={sigmoid(x):.4f}  σ'(аналит)={sigmoid_deriv(x):.4f}  σ'(числ)={numeric_deriv(sigmoid, x):.4f}")
```

Вывод:

x=-3  σ=0.0474  σ'(аналит)=0.0452  σ'(числ)=0.0452
x=-1  σ=0.2689  σ'(аналит)=0.1966  σ'(числ)=0.1966
x=+0  σ=0.5000  σ'(аналит)=0.2500  σ'(числ)=0.2500
x=+1  σ=0.7311  σ'(аналит)=0.1966  σ'(числ)=0.1966
x=+3  σ=0.9526  σ'(аналит)=0.0452  σ'(числ)=0.0452


Видно, как производная резко падает при удалении от нуля. На $x = \pm 3$ она уже почти в шесть раз меньше своего максимума.

#### Гиперболический тангенс: центрированный родственник сигмоиды

Гиперболический тангенс $\tanh$ — близкий родственник сигмоиды, но с одной важной разницей: его значения лежат в интервале $(-1, 1)$, а не $(0, 1)$. То есть выход $\tanh$ центрирован относительно нуля, что часто облегчает обучение.

{% capture notice %}
Определение (гиперболический тангенс). Функция гиперболического тангенса определяется как

$$
\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
$$

Её производная имеет вид:

$$
\tanh'(x) = 1 - \tanh^2(x)
$$

{% endcapture %}
{{ notice | markdownify }}

Заметьте структурное сходство с производной сигмоиды: и там, и там производная выражается через само значение функции. Это общее свойство «сигмоидоподобных» активаций. Максимум производной $\tanh$ равен $1$ (в точке $x=0$) — это в четыре раза больше, чем у сигмоиды. Поэтому $\tanh$ страдает от исчезающих градиентов меньше, и его исторически предпочитали в RNN.

[КАРТИНКА: график $\tanh(x)$ и его производной на одном поле. $\tanh$ — гладкая S-образная кривая от $-1$ до $1$. Производная — колокол с пиком $1$ в нуле. Для сравнения тонкой пунктирной линией показана производная сигмоиды с пиком $0.25$.]

#### ReLU: главная активация современных нейросетей

ReLU (Rectified Linear Unit) — это самая популярная функция активации в современных нейронных сетях, от свёрточных сетей до трансформеров.

{% capture notice %}
Определение (ReLU). Функция ReLU задаётся формулой

$$
\mathrm{ReLU}(x) = \max(0, x) = \begin{cases} x, & x > 0 \\ 0, & x \le 0 \end{cases}
$$

Её производная:

$$
\mathrm{ReLU}'(x) = \begin{cases} 1, & x > 0 \\ 0, & x < 0 \end{cases}
$$

В точке $x = 0$ производная формально не определена (есть излом). На практике её доопределяют нулём или единицей — это субградиент.
{% endcapture %}
{{ notice | markdownify }}

Интуитивно ReLU — это «диод» из электроники: положительный сигнал пропускается без искажений, отрицательный полностью отсекается. Простота этой функции — её главное достоинство. Вычисление производной — это просто проверка знака, никаких экспонент.

[КАРТИНКА: график ReLU — ломаная из двух частей: горизонтальный отрезок на оси $x$ для $x \le 0$ и наклонная прямая $y = x$ для $x > 0$. Рядом график производной — ступенька, равная нулю слева и единице справа от точки $x=0$. Точка излома выделена красным.]

Почему ReLU так хороша? Её производная либо равна $1$, либо $0$. На активных нейронах градиенты вообще не затухают — они проходят через слой без изменений. Это решает главную проблему сигмоиды. Однако есть и обратная сторона: если нейрон попал в зону $x < 0$, его градиент равен нулю, и веса перестают обновляться. Это явление называется dying ReLU — «мёртвые» нейроны. Для борьбы с ним придумали модификации: Leaky ReLU с маленьким наклоном слева ($f(x) = \max(0.01 x, x)$) и ELU.

```py
def relu(x):
    return x if x > 0 else 0.0

def relu_deriv(x):
    return 1.0 if x > 0 else 0.0

for x in [-2, -0.1, 0.1, 2]:
    print(f"x={x:+.1f}  ReLU={relu(x):.2f}  ReLU'={relu_deriv(x):.1f}")
```

Вывод:

x=-2.0  ReLU=0.00  ReLU'=0.0
x=-0.1  ReLU=0.00  ReLU'=0.0
x=+0.1  ReLU=0.10  ReLU'=1.0
x=+2.0  ReLU=2.00  ReLU'=1.0


Градиент действительно ведёт себя как «всё или ничего».

#### Softplus: гладкая версия ReLU

Иногда от излома в нуле хочется избавиться — например, когда требуется дважды дифференцируемая функция или нужна гарантированно положительная величина (масштаб распределения, дисперсия). Тогда используют softplus:

{% capture notice %}
Определение (softplus). Функция softplus задаётся формулой

$$
\mathrm{softplus}(x) = \ln(1 + e^x)
$$

Её производная — в точности сигмоида:

$$
\mathrm{softplus}'(x) = \frac{e^x}{1 + e^x} = \sigma(x)
$$

{% endcapture %}
{{ notice | markdownify }}

Это красивая связка: softplus — это «сглаженная» ReLU, а её производная — сигмоида. На больших положительных $x$ softplus практически совпадает с $x$, на больших отрицательных — почти равна нулю, а вокруг нуля плавно изгибается.

[КАРТИНКА: на одном графике три кривые: ReLU (с изломом), softplus (та же форма, но с плавным округлением в нуле) и линия $y = x$ как асимптота. Видно, как softplus стремится к ReLU при удалении от нуля.]

#### Логистическая функция потерь: производная как «ошибка»

Отдельно стоит рассмотреть функцию, которая сама по себе является функцией потерь — бинарную кросс-энтропию для одного объекта с истинной меткой $y \in \{0, 1\}$ и предсказанием $p = \sigma(z)$, где $z$ — выход линейной модели:

$$
L(z) = -\bigl[y \ln \sigma(z) + (1 - y) \ln(1 - \sigma(z))\bigr]
$$

Если мы аккуратно посчитаем её производную по $z$ (применяя цепное правило и тождество $\sigma'(z) = \sigma(z)(1-\sigma(z))$), получим поразительно простую формулу:

$$
\frac{dL}{dz} = \sigma(z) - y = p - y
$$

Это чистая магия. Производная всей логистической функции потерь по входу — это просто разность между предсказанием и правильным ответом. Не нужно дифференцировать ни логарифм, ни сигмоиду — они идеально сокращаются. Именно поэтому в реализациях нейронных сетей сигмоиду и кросс-энтропию объединяют в одну операцию (BCEWithLogitsLoss в PyTorch): это и численно стабильнее, и быстрее.

Проверим эту формулу численно:

```py
def bce_loss(z, y):
    p = sigmoid(z)
    return -(y * math.log(p) + (1 - y) * math.log(1 - p))

for (z, y) in [(2.0, 1), (2.0, 0), (-1.0, 1), (-1.0, 0)]:
    p = sigmoid(z)
    analytic = p - y
    numeric  = numeric_deriv(lambda zz: bce_loss(zz, y), z)
    print(f"z={z:+.1f} y={y}  p={p:.3f}  dL/dz: формула={analytic:+.4f}  числ={numeric:+.4f}")
```

Вывод:

z=+2.0 y=1  p=0.881  dL/dz: формула=-0.1192  числ=-0.1192
z=+2.0 y=0  p=0.881  dL/dz: формула=+0.8808  числ=+0.8808
z=-1.0 y=1  p=0.269  dL/dz: формула=-0.7311  числ=-0.7311
z=-1.0 y=0  p=0.269  dL/dz: формула=+0.2689  числ=+0.2689


Градиент имеет ясный смысл: если модель уверенно ошиблась (второй случай: предсказали $0.88$, а ответ — $0$), градиент огромный и толкает в правильную сторону. Если попала почти точно, градиент маленький. Это идеальное поведение для обучения.

[АНИМАЦИЯ: вертикальная шкала с предсказанием $p$ от $0$ до $1$ и истинной меткой $y = 1$ (отмечена красной точкой). Когда $p$ далеко от $y$, появляется длинная синяя стрелка градиента, тянущая $p$ к $y$. По мере приближения $p$ к $y$ стрелка укорачивается до нуля.]

#### Софтмакс и его производная (взгляд вперёд)

Когда классов больше двух, на выходе сети ставят функцию softmax — многомерное обобщение сигмоиды. Её мы подробно разберём позже, в главе о производных векторных функций, но идея та же: при паре «softmax + кросс-энтропия» производная по входному вектору сводится к разности $\hat{y} - y$, где $\hat{y}$ — вектор предсказанных вероятностей, $y$ — one-hot вектор правильного класса. Этот красивый результат — не случайность, а следствие сопряжённости логарифмической функции потерь с экспоненциальным семейством распределений.

[КАРТИНКА: схема выхода нейросети. Линейный слой выдаёт логиты $z_1, z_2, z_3$, через softmax они превращаются в вероятности $\hat y_1, \hat y_2, \hat y_3$. Снизу — истинный one-hot вектор $y = (0, 1, 0)$. Между ними нарисована стрелка с подписью «градиент = $\hat y - y$».]

### Производные высших порядков (DS)

Первая производная $f'(x)$ говорит нам о скорости изменения функции — о наклоне касательной. Но сама производная тоже является функцией, и мы можем спросить: а как быстро меняется скорость? Ответ даёт вторая производная. Она описывает кривизну графика, ускорение процесса, и именно на неё опираются продвинутые методы оптимизации в машинном обучении. Понимание производных высших порядков превращает линейное приближение первого порядка в квадратичное, позволяя точнее предсказывать поведение функции потерь и быстрее находить минимумы.

#### Определение и интуиция

Пусть $f$ дифференцируема в окрестности точки $x$, и её первая производная $f'(x)$ также является дифференцируемой. Тогда **вторая производная** $f''(x)$ — это производная от $f'(x)$. Формально:

$$
f''(x) = \lim_{h\to 0} \frac{f'(x+h)-f'(x)}{h} = \frac{d}{dx}\!\left(\frac{df}{dx}\right).
$$

Если $f(x)$ — положение объекта в момент $x$, то $f'(x)$ — скорость, а $f''(x)$ — ускорение. Положительное ускорение означает, что скорость растёт; отрицательное — что объект замедляется. В контексте графика: знак второй производной показывает, выгнута ли функция вверх (как чаша) или вниз (как холм).

{% capture notice %}
**Определение (производные высших порядков).** Пусть $f$ дифференцируема $n$ раз в некоторой окрестности точки $x$. Тогда $n$-я производная определяется рекурсивно:

$$
f^{(n)}(x) = \frac{d}{dx} f^{(n-1)}(x),
$$

причём $f^{(0)}(x) = f(x)$. Используются обозначения: $f''(x)$, $f'''(x)$, $f^{(4)}(x)$ и т.д., или $\frac{d^n f}{dx^n}$.
{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

Геометрически вторая производная отвечает за изгиб графика. Если $f''(x) > 0$, график вогнут вверх (convex), а касательные лежат ниже кривой. Если $f''(x) < 0$, график вогнут вниз (concave), а касательные — выше. Точки, где $f''(x)=0$ и происходит смена знака, называются точками перегиба — там кривая меняет направление изгиба.

[КАРТИНКА: график функции $f(x)=x^3-3x$. Отмечены два экстремума (где $f'(x)=0$) и точка перегиба в начале координат. На разных участках цветом показаны области с $f''>0$ (вогнутость вверх) и $f''<0$ (вогнутость вниз). Рядом — график второй производной $f''(x)=6x$, который меняет знак в нуле.]

В машинном обучении вторая производная даёт информацию о том, насколько «острый» минимум функции потерь. Острый минимум (большая вторая производная) означает, что параметры определены более уверенно, но и градиентный спуск может быть неустойчивым. Пологий минимум (маленькая вторая производная) — напротив, устойчивее, но сходимость медленнее.

#### Применение: анализ критических точек

Напомним, что для поиска экстремумов мы ищем точки, где первая производная равна нулю (стационарные точки). Но ноль первой производной не различает минимум, максимум и седло. Здесь вступает вторая производная.

{% capture notice %}
**Достаточное условие локального экстремума (второй производной).** Пусть $f'(a)=0$ и существует $f''(a)$. Тогда:
- если $f''(a) > 0$, то $a$ — точка локального минимума;
- если $f''(a) < 0$, то $a$ — точка локального максимума;
- если $f''(a)=0$, тест не даёт ответа (возможно, перегиб или экстремум высшего порядка).
{% endcapture %}

Интуитивно: если в стационарной точке график изогнут вверх, то со всех сторон функция выше, значит, это минимум. Если изогнут вниз — максимум. В оптимизации это помогает понять, действительно ли мы нашли минимум потерь или застряли на седловой точке.

[КАРТИНКА: два графика: парабола $y=x^2$ с $f''>0$ и парабола $y=-x^2$ с $f''<0$. В каждой точке экстремума отмечена касательная (горизонтальная) и стрелки, показывающие направление выпуклости.]

#### Квадратичное приближение и метод Ньютона

Если первая производная даёт линейное приближение, то вторая позволяет строить **квадратичное приближение** — параболу, которая ещё точнее описывает функцию вблизи точки. Разложение Тейлора второго порядка:

$$
f(a+h) \approx f(a) + f'(a)h + \frac{1}{2} f''(a) h^2.
$$

Эта парабола имеет тот же наклон и ту же кривизну, что и исходная функция. Идея метода Ньютона для поиска минимума: вместо того чтобы идти в направлении антиградиента, мы аппроксимируем функцию параболой и прыгаем сразу в её минимум. Шаг Ньютона:

$$
x_{n+1} = x_n - \frac{f'(x_n)}{f''(x_n)}.
$$

Этот метод сходится гораздо быстрее градиентного спуска, но требует вычисления второй производной. В многомерном случае аналогом является метод Ньютона с матрицей Гессе, который слишком дорог для больших нейросетей, но понимание его работы помогает строить более эффективные оптимизаторы (AdaHessian, K-FAC).

[АНИМАЦИЯ: сравнение градиентного спуска и метода Ньютона на функции $f(x)=x^4 + 2x^2 + \sin x$. Градиентный спуск делает много маленьких шагов, а Ньютон — один-два больших, сразу попадая в минимум благодаря учёту кривизны.]

#### Вычисление старших производных в коде

Численно $n$-ю производную можно вычислить повторным применением конечных разностей. Для второй производной формула центральной разности:

$$
f''(x) \approx \frac{f(x+h) - 2f(x) + f(x-h)}{h^2}.
$$

Реализуем функцию, вычисляющую до второй производной, и сравним с аналитическими значениями для $f(x)=x^4 + \sin x$.

```python
import numpy as np

def derivatives_numerical(f, x, h=1e-5):
    """Возвращает f(x), f'(x), f''(x) численно."""
    fx = f(x)
    f1 = (f(x+h) - f(x-h)) / (2*h)
    f2 = (f(x+h) - 2*fx + f(x-h)) / (h**2)
    return fx, f1, f2

# Тест: f(x) = x^4 + sin(x)
f = lambda x: x**4 + np.sin(x)
x0 = 1.0
val, d1, d2 = derivatives_numerical(f, x0)
# Аналитические: f' = 4x^3 + cos(x), f'' = 12x^2 - sin(x)
true_d1 = 4*x0**3 + np.cos(x0)
true_d2 = 12*x0**2 - np.sin(x0)
print(f"f({x0}) = {val:.5f}")
print(f"f' : числен. {d1:.5f}, аналит. {true_d1:.5f}")
print(f"f'': числен. {d2:.5f}, аналит. {true_d2:.5f}")
```

Вывод:
```
f(1.0) = 1.84147
f' : числен. 4.54030, аналит. 4.54030
f'': числен. 11.15853, аналит. 11.15853
```

Теперь получим вторую производную через автоматическое дифференцирование PyTorch, дважды вызвав градиент.

```python
import torch

x = torch.tensor(1.0, requires_grad=True)
y = x**4 + torch.sin(x)
# Первая производная
dy = torch.autograd.grad(y, x, create_graph=True)[0]
# Вторая производная: градиент от dy
d2y = torch.autograd.grad(dy, x)[0]
print(f"PyTorch f'' = {d2y.item():.5f}")
```

Вывод:
```
PyTorch f'' = 11.15853
```

Видно, что PyTorch без труда вычисляет старшие производные, создавая граф вычислений для самого градиента. Этот механизм используют, например, для вычисления штрафов на кривизну (регуляризация градиента) или для мета-обучения, где нужно дифференцировать по гиперпараметрам.

#### Связь с машинным обучением

В анализе функции потерь вторая производная (или её многомерное обобщение — матрица Гессе) раскрывает геометрию ландшафта потерь. Большая положительная кривизна вдоль какого-то направления означает, что функция потерь резко меняется, и в этом направлении градиентный спуск может осциллировать. Маленькая кривизна — пологий овраг, где спуск медленный. Именно эту информацию используют методы второго порядка для адаптивного выбора шага.

Кроме того, в некоторых архитектурах (например, в нейронных обыкновенных дифференциальных уравнениях) требуется вычислять вторые производные для обратного распространения через решатель ОДУ. Понимание производных высших порядков становится критически важным.

#### Заключение

- Вторая производная измеряет кривизну функции и ускорение её изменения, подобно тому как первая измеряет скорость.
- Геометрически знак $f''$ определяет выпуклость: $f''>0$ — вогнутость вверх (минимум), $f''<0$ — вогнутость вниз (максимум); точки перегиба — смена знака $f''$.
- Квадратичное приближение $f(a+h)\approx f(a)+f'(a)h+\frac12 f''(a)h^2$ использует вторую производную для более точного предсказания, что лежит в основе метода Ньютона.
- В машинном обучении старшие производные помогают анализировать ландшафт потерь, строить оптимизаторы второго порядка и решать задачи мета-обучения.
- Вычислить вторую производную можно численно (конечные разности) или с помощью автоматического дифференцирования, которое строит граф производных и позволяет брать градиент повторно.

### Производные высших порядков (CO)

До сих пор мы работали с первой производной — той самой, которая показывает скорость изменения функции и задаёт наклон касательной. Но первая производная — это сама по себе функция, и её тоже можно дифференцировать. Так возникают производные второго, третьего и более высоких порядков. Они описывают всё более тонкие свойства поведения функции: не просто «куда она движется», но и «как меняется её движение», «как меняется это изменение» и так далее. В машинном обучении производные высших порядков играют ключевую роль в методах второго порядка оптимизации (например, методе Ньютона), в анализе кривизны функции потерь, в разложениях Тейлора и в современных техниках вроде sharpness-aware minimization.

#### От скорости к ускорению

Лучшая интуиция для производных высших порядков приходит из физики. Если $x(t)$ — это положение объекта во времени, то $x'(t)$ — его скорость (как быстро меняется положение), а $x''(t)$ — ускорение (как быстро меняется сама скорость). Третья производная — это рывок (jerk), то есть скорость изменения ускорения; она ощущается, например, когда машина резко начинает тормозить.

{% capture notice %}
Определение (производная $n$-го порядка). Пусть функция $f: \mathbb{R} \to \mathbb{R}$ дифференцируема в окрестности точки $x_0$, и её производная $f'(x)$ снова дифференцируема. Тогда второй производной функции $f$ в точке $x_0$ называется производная её производной:

$$
f''(x_0) = \frac{d}{dx}\bigl(f'(x)\bigr)\Big|_{x = x_0}
$$

По индукции, производной $n$-го порядка называется

$$
f^{(n)}(x) = \frac{d}{dx}\bigl(f^{(n-1)}(x)\bigr)
$$

Используются обозначения $f''$, $f'''$, $f^{(4)}, \dots, f^{(n)}$, а также нотация Лейбница $\dfrac{d^n f}{dx^n}$.
{% endcapture %}
{{ notice | markdownify }}

Ключевая мысль: производная сама — это функция, поэтому её можно дифференцировать дальше. Если функция «достаточно гладкая», этот процесс можно повторять сколько угодно раз.

[КАРТИНКА: три графика друг под другом с общей осью $x$. Верхний — гладкая функция $f(x) = \sin(x) + 0.3 x^2$. Средний — её первая производная $f'(x)$ (наклон касательных к верхнему графику). Нижний — вторая производная $f''(x)$ (наклон касательных к среднему). Вертикальные пунктирные линии показывают одну и ту же точку $x_0$ на всех трёх графиках, чтобы было видно, как значение на нижнем графике равно наклону среднего.]

#### Геометрический смысл второй производной: кривизна и выпуклость

Вторая производная имеет очень наглядный геометрический смысл — она описывает, как искривлён график. Если $f''(x) > 0$, то наклон $f'(x)$ растёт, и кривая загибается вверх — функция выпукла вниз (или просто «выпукла», convex). Если $f''(x) < 0$, наклон убывает, и кривая загибается вниз — функция вогнута (concave). Точка, в которой $f''$ меняет знак, называется точкой перегиба.

{% capture notice %}
**Свойство (выпуклость через вторую производную)**. Если на интервале $f''(x) \ge 0$, то функция $f$ выпукла на этом интервале. Если $f''(x) \le 0$ — вогнута. Если $f''(x_0) = 0$ и при переходе через $x_0$ знак $f''$ меняется, то $x_0$ — точка перегиба.
{% endcapture %}
{{ notice | markdownify }}

[КАРТИНКА: три графика рядом. Слева — выпуклая чаша $y = x^2$ с подписью «$f''>0$, выпукла», в нескольких точках нарисованы маленькие зелёные дужки, изгибающиеся вверх. В центре — вогнутая шапка $y = -x^2$ с дужками, изгибающимися вниз («$f''<0$, вогнута»). Справа — кубическая парабола $y = x^3$ с отмеченной точкой перегиба в начале координат, где знак $f''$ меняется.]

В машинном обучении выпуклость функции потерь — это огромное благо. Если функция потерь строго выпукла, у неё единственный глобальный минимум, и градиентный спуск гарантированно к нему сходится. Линейная и логистическая регрессии имеют выпуклые функции потерь — поэтому они так надёжно обучаются. У нейронных сетей функция потерь не выпукла, и именно поэтому обучение глубоких моделей — это всегда искусство, а не точная наука.

Проверка точки на минимум через вторую производную — стандартный приём, известный со школы:

{% capture notice %}
Достаточное условие экстремума (тест второй производной). Пусть $f'(x_0) = 0$. Тогда:
- если $f''(x_0) > 0$, то $x_0$ — точка локального минимума;
- если $f''(x_0) < 0$, то $x_0$ — точка локального максимума;
- если $f''(x_0) = 0$, тест неинформативен — нужно изучать высшие производные.
{% endcapture %}
{{ notice | markdownify }}

#### Вычисление высших производных в коде

Давайте напишем простой численный «дифференцирующий оператор», который применим к функции дважды, чтобы получить вторую производную:

```py
def D(f, h=1e-4):
    """Возвращает функцию — численную производную f."""
    return lambda x: (f(x + h) - f(x - h)) / (2 * h)

import math
f  = lambda x: math.sin(x) + 0.3 * x**2
f1 = D(f)
f2 = D(f1)
f3 = D(f2)

for x in [-1.0, 0.0, 1.0]:
    print(f"x={x:+.1f}  f={f(x):+.4f}  f'={f1(x):+.4f}  f''={f2(x):+.4f}  f'''={f3(x):+.4f}")
```

Вывод:

x=-1.0  f=-0.5415  f'=-0.0003  f''=+1.4415  f'''=+0.5403
x=+0.0  f=+0.0000  f'=+1.0000  f''=+0.6000  f'''=-1.0000
x=+1.0  f=+1.4415  f'=+1.1403  f''=-0.2415  f'''=-0.5403

Сверим с аналитикой: для $f(x) = \sin x + 0.3 x^2$ имеем $f'(x) = \cos x + 0.6 x$, $f''(x) = -\sin x + 0.6$, $f'''(x) = -\cos x$. При $x = 0$ получаем $f' = 1$, $f'' = 0.6$, $f''' = -1$ — в точности как в выводе. При этом обратите внимание: чем больше порядок, тем больше численная ошибка, ведь мы много раз делим на маленькое число. Это типичная проблема численного дифференцирования, и в продакшен-коде для высших производных используют либо символьное вычисление (SymPy), либо автоматическое дифференцирование (PyTorch, JAX).

#### Производные высших порядков в PyTorch

Современные автодифф-фреймворки умеют вычислять производные любого порядка, многократно применяя обратный проход. Это используется, например, в физически-информированных нейронных сетях (PINN), где функция потерь содержит вторые производные сети по входам.

```py
import torch
x = torch.tensor(1.0, requires_grad=True)
y = torch.sin(x) + 0.3 * x**2

g1, = torch.autograd.grad(y, x, create_graph=True)
g2, = torch.autograd.grad(g1, x, create_graph=True)
g3, = torch.autograd.grad(g2, x)
print(f"f'={g1.item():.4f}  f''={g2.item():.4f}  f'''={g3.item():.4f}")
```

Вывод:

f'=1.1403  f''=-0.2415  f'''=-0.5403

Цифры совпадают с нашей ручной численной оценкой. Ключевая деталь — параметр create_graph=True: он говорит PyTorch не выбрасывать вычислительный граф после backward, а сохранить его для повторного дифференцирования.

#### Формула Тейлора: главная причина, по которой нам нужны высшие производные

Помимо анализа выпуклости, у высших производных есть ещё одна, возможно даже более важная роль: они являются коэффициентами разложения функции в ряд Тейлора — приближения функции многочленом сколь угодно высокого порядка.

{% capture notice %}
**Теорема (формула Тейлора с остатком Пеано)**. Пусть функция $f$ имеет в точке $x_0$ производные до порядка $n$ включительно. Тогда

$$
f(x_0 + h) = f(x_0) + f'(x_0)\,h + \frac{f''(x_0)}{2!}\,h^2 + \dots + \frac{f^{(n)}(x_0)}{n!}\,h^n + o(h^n)
$$

{% endcapture %}
{{ notice | markdownify }}

Смысл формулы такой: первая производная даёт линейное приближение, вторая добавляет квадратичную поправку, третья — кубическую, и так далее. Чем больше производных мы знаем, тем точнее можем восстановить функцию в окрестности точки.

[АНИМАЦИЯ: график функции $e^x$. На него последовательно накладываются приближения Тейлора возрастающего порядка: сначала константа $1$, потом прямая $1 + x$, потом парабола $1 + x + x^2/2$, кубика $1 + x + x^2/2 + x^3/6$ и так далее. С каждым шагом приближение «облегает» исходную кривую всё лучше, особенно в окрестности нуля.]

Именно квадратичная поправка стоит за методом Ньютона в оптимизации. Если в окрестности текущей точки $x_k$ мы приближаем функцию потерь параболой $L(x_k) + L'(x_k)(x - x_k) + \tfrac{1}{2}L''(x_k)(x-x_k)^2$ и аналитически минимизируем её, получаем формулу шага:

$$
x_{k+1} = x_k - \frac{L'(x_k)}{L''(x_k)}
$$

Это гораздо мощнее обычного градиентного спуска: метод Ньютона учитывает кривизну и сам подбирает оптимальный размер шага. Реализуем его:

```py
def newton_step(L, x, h=1e-4):
    L1 = (L(x + h) - L(x - h)) / (2 * h)
    L2 = (L(x + h) - 2 * L(x) + L(x - h)) / h**2
    return x - L1 / L2

L = lambda x: (x - 3)**2 + 0.5 * (x - 3)**4
x = 0.0
for k in range(6):
    x = newton_step(L, x)
    print(f"шаг {k+1}: x = {x:.6f},  L(x) = {L(x):.6f}")
```

Вывод:

шаг 1: x = 1.413043, L(x) = 4.500003
шаг 2: x = 2.184782, L(x) = 0.872768
шаг 3: x = 2.620664, L(x) = 0.150863
шаг 4: x = 2.842857, L(x) = 0.025308
шаг 5: x = 2.943231, L(x) = 0.003315
шаг 6: x = 2.982008, L(x) = 0.000332

За шесть шагов мы пришли к минимуму $x = 3$ с приличной точностью. Сравнительно с градиентным спуском с фиксированным шагом это очень быстро.

[КАРТИНКА: график функции потерь $L(x)$. Из начальной точки $x_0$ нарисована парабола — квадратичное приближение Тейлора в этой точке. Её вершина — следующая точка $x_1$. Из $x_1$ построена новая парабола, её вершина — $x_2$. И так далее, точки быстро сходятся к минимуму $L$.]

В многомерном случае роль второй производной играет матрица Гессе $H = \nabla^2 L$, и метод Ньютона превращается в $x_{k+1} = x_k - H^{-1} \nabla L$. Из-за дороговизны обращения матрицы Гессе в нейросетях чистый Ньютон не используют, но идею учёта кривизны эксплуатируют квазиньютоновские методы (L-BFGS), а также адаптивные оптимизаторы вроде Adam, которые оценивают «эффективную кривизну» через моменты градиента.

#### Где ещё высшие производные встречаются в ML

Кроме оптимизации, вторые производные появляются в нескольких важных контекстах. Анализ резкости минимума: если в минимуме $|f''|$ велик, то «чаша» узкая и крутая — модель в такой точке часто плохо обобщает. Современные методы (SAM, sharpness-aware minimization) явно штрафуют большую кривизну. Регуляризация физически-информированных сетей: уравнения в частных производных содержат вторые производные, и сеть учится так, чтобы её вторые производные удовлетворяли уравнению. Доверительные интервалы и Bayes: матрица Гессе log-правдоподобия (информационная матрица Фишера) задаёт ковариацию апостериорного распределения параметров.

[КАРТИНКА: две функции потерь рядом. Слева — узкий острый минимум (большое $|f''|$), модель в такой точке неустойчива к малым возмущениям весов. Справа — широкий пологий минимум (малое $|f''|$), модель гораздо более робастна. Над каждым минимумом нарисована парабола квадратичного приближения, показывающая разную кривизну.]

#### Выводы

Производная $n$-го порядка $f^{(n)}$ получается последовательным дифференцированием функции $n$ раз. Это снова функция, которую можно изучать как самостоятельный объект.
Первая производная — это скорость изменения, вторая — ускорение (скорость изменения скорости), третья — рывок, и так далее. Физическая аналогия здесь работает безотказно.
Знак второй производной определяет выпуклость: $f''>0$ — выпукла, $f''<0$ — вогнута. Точки перегиба — это места смены знака $f''$.
Тест второй производной даёт достаточное условие экстремума: $f'(x_0)=0$ и $f''(x_0)>0 \Rightarrow$ минимум; $f''(x_0)<0 \Rightarrow$ максимум.
Формула Тейлора выражает функцию в окрестности точки через её производные всех порядков. Чем больше производных, тем точнее многочленное приближение.
Метод Ньютона использует первую и вторую производные для квадратичного приближения и шагает прямо в вершину параболы — гораздо быстрее простого градиентного спуска.
В многомерном машинном обучении прямой аналог $f''$ — матрица Гессе; на её свойствах построены квазиньютоновские методы (L-BFGS), анализ резкости минимумов и информационная геометрия (матрица Фишера).
Численное вычисление высших производных накапливает ошибки округления; на практике для них используют автоматическое дифференцирование с create_graph=True или символьные библиотеки.

Хотите, чтобы в следующей главе мы перешли к многомерному случаю — частным производным, градиенту и матрице Гессе — как естественному обобщению всего, что мы изучили в одномерном анализе?

### Матрица Якоби: вектор-функции от вектора (DS)

До сих пор мы изучали производные скалярных функций одной переменной. Но в машинном обучении почти любая модель — это функция, которая принимает на вход вектор (признаки, пиксели) и выдаёт вектор (предсказания, логиты) или скаляр (потери). Даже один слой нейронной сети $f(\mathbf{x}) = \sigma(\mathbf{W}\mathbf{x} + \mathbf{b})$ отображает вектор $\mathbf{x} \in \mathbb{R}^n$ в вектор $\mathbf{y} \in \mathbb{R}^m$. Как описать производную такой функции? Ответ даёт матрица Якоби — естественное обобщение понятия производной на случай, когда и вход, и выход многомерны.

#### Определение и интуиция

Пусть $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$ — дифференцируемая вектор-функция, то есть набор из $m$ скалярных функций $\mathbf{f}(\mathbf{x}) = [f_1(\mathbf{x}), f_2(\mathbf{x}), \dots, f_m(\mathbf{x})]^\top$. Зафиксируем точку $\mathbf{a} \in \mathbb{R}^n$. Мы хотим понять, как малые изменения входа $\mathbf{h}$ отражаются на выходе.

В скалярном случае производная давала линейное приближение: $f(a+h) \approx f(a) + f'(a)h$. В векторном случае линейное приближение выглядит так же, но коэффициент теперь — матрица:

$$
\mathbf{f}(\mathbf{a} + \mathbf{h}) \approx \mathbf{f}(\mathbf{a}) + \mathbf{J}(\mathbf{a})\, \mathbf{h},
$$

где $\mathbf{J}(\mathbf{a})$ — матрица размера $m \times n$. Чтобы найти её элементы, рассмотрим $i$-ю компоненту выхода $f_i(\mathbf{x})$. Её изменение при добавлении $\mathbf{h}$ в первом порядке описывается частными производными по всем входным переменным:

$$
f_i(\mathbf{a}+\mathbf{h}) \approx f_i(\mathbf{a}) + \frac{\partial f_i}{\partial x_1}(\mathbf{a})h_1 + \cdots + \frac{\partial f_i}{\partial x_n}(\mathbf{a})h_n.
$$

Следовательно, строка $i$ матрицы $\mathbf{J}$ состоит из частных производных $f_i$ по всем $x_j$. Это приводит нас к формальному определению.

{% capture notice %}
**Определение (матрица Якоби).** Пусть $\mathbf{f} : \mathbb{R}^n \to \mathbb{R}^m$ дифференцируема в точке $\mathbf{a}$. Матрицей Якоби $\mathbf{J}_{\mathbf{f}}(\mathbf{a})$ называется матрица размера $m \times n$, элементы которой — частные производные компонент $\mathbf{f}$ по координатам $\mathbf{x}$:

$$
[\mathbf{J}_{\mathbf{f}}(\mathbf{a})]_{ij} = \frac{\partial f_i}{\partial x_j}(\mathbf{a}), \qquad i=1,\dots,m, \; j=1,\dots,n.
$$

{% endcapture %}
<div class="notice--success">{{ notice | markdownify }}</div>

Если $m=1$ (функция выдаёт скаляр), матрица Якоби превращается в вектор-строку — транспонированный градиент: $\mathbf{J} = \nabla f(\mathbf{a})^\top$. Если $n=1$ (функция одной переменной), это вектор-столбец производных каждой компоненты. А если и $m=1$, и $n=1$, это обычная производная. Таким образом, якобиан объединяет все эти понятия в единую конструкцию.

Представьте, что $\mathbf{f}$ — это преобразование координат на карте: из широты и долготы $(x_1, x_2)$ в декартовы координаты $(y_1, y_2)$. Матрица Якоби в точке показывает, как маленький шаг на север или восток пересчитывается в горизонтальное и вертикальное смещение на плоскости. Каждый элемент $\partial f_i / \partial x_j$ описывает, насколько сильно изменение $j$-й входной координаты влияет на $i$-ю выходную.

[КАРТИНКА: двумерная иллюстрация преобразования $\mathbf{f}$: слева — равномерная сетка малых окружностей в пространстве входов $\mathbb{R}^2$, справа — их образы в пространстве выходов. Окружности превращаются в эллипсы, а матрица Якоби описывает это линейное искажение вблизи отмеченной точки. Показаны векторы базиса и их образы через якобиан.]

#### Якобиан как касательное линейное отображение

Главное свойство матрицы Якоби — она задаёт наилучшее локальное линейное приближение вектор-функции. Точно так же, как производная скалярной функции даёт касательную прямую, якобиан даёт касательное отображение между пространствами. Если входное приращение $\mathbf{h}$ мало, то $\mathbf{f}(\mathbf{a}+\mathbf{h}) - \mathbf{f}(\mathbf{a}) \approx \mathbf{J}(\mathbf{a})\mathbf{h}$.

В машинном обучении это означает, что при обратном распространении ошибки через слой с функцией $\mathbf{f}$ градиент потерь $L$ по входу $\mathbf{x}$ выражается через градиент по выходу $\mathbf{y}$ и якобиан:

$$
\nabla_{\mathbf{x}} L = \mathbf{J}_{\mathbf{f}}(\mathbf{x})^\top \nabla_{\mathbf{y}} L.
$$

Именно эта операция — умножение градиента на транспонированную матрицу Якоби — и составляет суть обратного распространения. Для каждого слоя мы вычисляем якобиан, и PyTorch/TensorFlow делают это автоматически.

[АНИМАЦИЯ: схема обратного распространения. Прямой проход: $\mathbf{x} \to \mathbf{y} = \mathbf{f}(\mathbf{x}) \to L$. Обратный проход: градиент $\nabla_{\mathbf{y}} L$ умножается на $\mathbf{J}^\top$, чтобы получить $\nabla_{\mathbf{x}} L$. Стрелки подсвечиваются, показывая поток градиентов.]

#### Пример: аффинное преобразование и функция активации

Рассмотрим типичный слой нейронной сети $\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}$ и поэлементную сигмоиду $\mathbf{y} = \sigma(\mathbf{z})$. Вычислим их якобианы.

Для линейного преобразования $\mathbf{f}(\mathbf{x}) = \mathbf{W}\mathbf{x}$, $f_i = \sum_{j} W_{ij} x_j$. Частная производная $\partial f_i / \partial x_j = W_{ij}$, поэтому якобиан в любой точке просто равен матрице $\mathbf{W}$ размера $m \times n$.

Для сигмоиды $\mathbf{y} = [\sigma(z_1), \dots, \sigma(z_m)]^\top$ зависимость $y_i$ от $z_k$ есть только при $i=k$, поэтому $\partial y_i / \partial z_k = 0$ при $i\neq k$, и $\sigma'(z_i)$ при $i=k$. Таким образом, якобиан — диагональная матрица $\operatorname{diag}(\sigma'(z_1), \dots, \sigma'(z_m))$.

Произведение этих якобианов (в правильном порядке) даёт якобиан композиции двух слоёв, что позволяет передавать градиент сквозь всю сеть.

#### Код: строим якобиан своими руками

Численно вычислить якобиан можно конечными разностями: варьируем каждую входную переменную и смотрим изменение всех выходов. Реализуем функцию `jacobian_numerical` и проверим её на простой вектор-функции $\mathbf{f}(x_1, x_2) = [x_1^2 + x_2,\; \sin(x_1) \cdot x_2]^\top$.

```python
import numpy as np

def jacobian_numerical(f, x, h=1e-5):
    """Численный якобиан f: R^n -> R^m в точке x."""
    x = np.asarray(x, dtype=float)
    n = len(x)
    f0 = np.asarray(f(x), dtype=float)
    m = len(f0)
    J = np.zeros((m, n))
    for j in range(n):
        x_plus = x.copy()
        x_plus[j] += h
        f_plus = np.asarray(f(x_plus), dtype=float)
        J[:, j] = (f_plus - f0) / h
    return J

# Пример: f(x) = [x1^2 + x2, sin(x1)*x2]
def f(x):
    return np.array([x[0]**2 + x[1], np.sin(x[0]) * x[1]])

# Аналитический якобиан
def jacobian_analytical(x):
    return np.array([
        [2*x[0], 1.0],
        [np.cos(x[0])*x[1], np.sin(x[0])]
    ])

x0 = np.array([1.0, 2.0])
J_num = jacobian_numerical(f, x0)
J_an  = jacobian_analytical(x0)
print("Численный якобиан:\n", J_num)
print("Аналитический якобиан:\n", J_an)
```

Вывод:
```
Численный якобиан:
 [[2.        1.       ]
  [1.080604  0.841471]]
Аналитический якобиан:
 [[2.        1.       ]
  [1.080604  0.841471]]
```

Теперь продемонстрируем работу автоматического дифференцирования: PyTorch позволяет вычислить якобиан вектор-функции «одним нажатием» с помощью `torch.autograd.functional.jacobian`.

```python
import torch

def f_torch(x):
    return torch.stack([x[0]**2 + x[1], torch.sin(x[0]) * x[1]])

x_t = torch.tensor([1.0, 2.0], requires_grad=True)
J_auto = torch.autograd.functional.jacobian(f_torch, x_t)
print("Якобиан PyTorch:\n", J_auto.numpy())
```

Вывод:
```
Якобиан PyTorch:
 [[2.        1.       ]
  [1.080604  0.841471]]
```

Совпадение полное. Под капотом PyTorch вычисляет частные производные, последовательно беря градиент каждой выходной компоненты по входу. Для больших матриц это может быть затратно, и в реальных сетях используются более эффективные методы (вектор-якобиановы произведения), но идея остаётся той же.

#### Применение в машинном обучении

Матрица Якоби — это «скелет» обратного распространения. Обучая сеть, мы не вычисляем весь якобиан каждого слоя целиком — нам достаточно умножать градиент на транспонированный якобиан, что делается с помощью операции `vjp` (vector-Jacobian product). Этот трюк лежит в основе всех библиотек глубокого обучения.

Другой важный пример — **нормализующие потоки (normalizing flows)**. Это генеративные модели, которые преобразуют простое распределение (например, гауссово) в сложное с помощью обратимой дифференцируемой функции $\mathbf{g}$. Чтобы вычислить плотность вероятности преобразованных данных, используется формула замены переменных, в которой фигурирует определитель матрицы Якоби $\det \mathbf{J}_{\mathbf{g}}$. Без понимания якобиана невозможно ни построить такой поток, ни обучить его.

#### Заключение

- Матрица Якоби вектор-функции $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$ — это матрица размера $m \times n$, состоящая из всех частных производных $\partial f_i / \partial x_j$. Она обобщает понятие производной на многомерный случай.
- Интуитивно якобиан задаёт линейное приближение: $\mathbf{f}(\mathbf{x}+\mathbf{h}) \approx \mathbf{f}(\mathbf{x}) + \mathbf{J}(\mathbf{x})\mathbf{h}$. Он показывает, как малые возмущения входа преобразуются в возмущения выхода.
- В машинном обучении якобиан лежит в основе обратного распространения ошибки: градиент по входу получается умножением градиента по выходу на транспонированный якобиан. Автоматическое дифференцирование в библиотеках эффективно вычисляет именно это.
- Якобиан также необходим в нормализующих потоках и других генеративных моделях, где требуется вычисление определителя якобиана.
- Понимание якобиана позволяет видеть сквозь «чёрный ящик» нейросетевых слоёв и осознанно проектировать собственные дифференцируемые модули.

### Вектор-функции от вектора: матрица Якоби

До сих пор мы рассматривали функции, которые либо принимают число и возвращают число ($f: \mathbb{R} \to \mathbb{R}$), либо принимают вектор и возвращают число ($f: \mathbb{R}^n \to \mathbb{R}$ — такие функции называют скалярными полями, их производная — это градиент). Но в машинном обучении гораздо чаще встречаются функции более общего вида: они принимают вектор и возвращают тоже вектор. Каждый слой нейронной сети — это именно такое отображение: на вход поступает вектор активаций, на выход — другой вектор. Чтобы говорить о производной таких отображений, нам нужен новый объект — матрица Якоби.

#### Что такое вектор-функция от вектора

Начнём с аккуратного определения. Вектор-функция от вектора — это отображение, которое каждой точке из одного пространства сопоставляет точку из другого.

{% capture notice %}
Определение (вектор-функция от вектора). Отображение $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$, которое каждому вектору $\mathbf{x} = (x_1, \dots, x_n)$ сопоставляет вектор

$$
\mathbf{f}(\mathbf{x}) = \begin{bmatrix} f_1(x_1, \dots, x_n) \\ f_2(x_1, \dots, x_n) \\ \vdots \\ f_m(x_1, \dots, x_n) \end{bmatrix}
$$

называется вектор-функцией от вектора. Каждая компонента $f_i: \mathbb{R}^n \to \mathbb{R}$ — это обычная скалярная функция многих переменных.
{% endcapture %}
{{ notice | markdownify }}

Простой пример: отображение $\mathbf{f}: \mathbb{R}^2 \to \mathbb{R}^2$, заданное формулами $f_1(x, y) = x^2 + y$, $f_2(x, y) = \sin(xy)$. Это машина, которая берёт точку плоскости и переносит её в другую точку плоскости.

[КАРТИНКА: две плоскости рядом, соединённые широкой стрелкой с подписью $\mathbf{f}$. На левой — точка $\mathbf{x} = (x_1, x_2)$ во входном пространстве $\mathbb{R}^n$. На правой — соответствующая ей точка $\mathbf{f}(\mathbf{x})$ в выходном пространстве $\mathbb{R}^m$. Под левой плоскостью подпись «вход $\mathbb{R}^n$», под правой — «выход $\mathbb{R}^m$».]

В машинном обучении такие отображения буквально вездесущи. Полносвязный слой нейросети с $n$ входами и $m$ выходами — это вектор-функция $\mathbf{f}(\mathbf{x}) = W \mathbf{x} + \mathbf{b}$, где $W$ — матрица весов $m \times n$. Применение softmax к вектору логитов длины $K$ — это отображение $\mathbb{R}^K \to \mathbb{R}^K$. Эмбеддинг-слой превращает индекс слова в плотный вектор размерности $d$ — это $\mathbb{R}^1 \to \mathbb{R}^d$. Вся нейросеть от входных пикселей до выходных вероятностей — это композиция таких вектор-функций.

#### От производной к матрице

Как определить производную для $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$? Вспомним идею из первых глав: производная — это коэффициент наилучшего линейного приближения. В одномерном случае это было число. В случае $\mathbb{R}^n \to \mathbb{R}$ — это вектор-градиент. Что же будет, когда и вход, и выход — векторы?

Интуиция подсказывает: нам нужен объект, который умеет принимать вектор приращения $\mathbf{h}$ во входном пространстве и выдавать вектор приращения $\Delta \mathbf{f}$ в выходном пространстве, причём это преобразование должно быть линейным. А линейное отображение между конечномерными пространствами — это, как мы знаем из линейной алгебры, матрица. Эта матрица и называется матрицей Якоби.

{% capture notice %}
Определение (матрица Якоби). Пусть $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$ дифференцируема в точке $\mathbf{x}_0$. Матрицей Якоби функции $\mathbf{f}$ в точке $\mathbf{x}_0$ называется матрица размера $m \times n$, составленная из всех частных производных её компонент:

$$
J_{\mathbf{f}}(\mathbf{x}_0) = \begin{bmatrix}
\dfrac{\partial f_1}{\partial x_1} & \dfrac{\partial f_1}{\partial x_2} & \cdots & \dfrac{\partial f_1}{\partial x_n} \\
\dfrac{\partial f_2}{\partial x_1} & \dfrac{\partial f_2}{\partial x_2} & \cdots & \dfrac{\partial f_2}{\partial x_n} \\
\vdots & \vdots & \ddots & \vdots \\
\dfrac{\partial f_m}{\partial x_1} & \dfrac{\partial f_m}{\partial x_2} & \cdots & \dfrac{\partial f_m}{\partial x_n}
\end{bmatrix}
$$

Элемент в $i$-й строке и $j$-м столбце равен $\dfrac{\partial f_i}{\partial x_j}(\mathbf{x}_0)$.
{% endcapture %}
{{ notice | markdownify }}

Ключевое правило для запоминания структуры: строки — это выходы, столбцы — это входы. В $i$-й строке стоит градиент $i$-й компоненты $f_i$ как функции от всех входов. В $j$-м столбце стоят производные всех выходов по $j$-му входу.

[КАРТИНКА: схема матрицы Якоби размера $m \times n$. Слева от матрицы — вертикальная подпись «выходы $f_1, f_2, \dots, f_m$» со стрелкой вниз. Сверху — горизонтальная подпись «входы $x_1, x_2, \dots, x_n$» со стрелкой вправо. Одна строка матрицы выделена цветом и подписана «градиент $f_i$»; один столбец выделен другим цветом и подписан «производные всех $f_j$ по $x_k$».]

Концептуально матрица Якоби — это многомерное обобщение производной. Все знакомые нам формулы превращаются в её частные случаи: для $n=1, m=1$ это просто число $f'(x)$, для $n > 1, m=1$ — это строка-градиент $\nabla f^\top$, для общего случая — полноценная матрица.

#### Якобиан как линейное приближение

Главное свойство матрицы Якоби — она задаёт линейное приближение вектор-функции.

{% capture notice %}
Свойство (линейное приближение). Если $\mathbf{f}$ дифференцируема в $\mathbf{x}_0$, то для малого $\mathbf{h}$:

$$
\mathbf{f}(\mathbf{x}_0 + \mathbf{h}) = \mathbf{f}(\mathbf{x}_0) + J_{\mathbf{f}}(\mathbf{x}_0) \, \mathbf{h} + o(\|\mathbf{h}\|)
$$

{% endcapture %}
{{ notice | markdownify }}

Это та же формула, что и в одномерном случае, только число $f'(x_0)$ заменено на матрицу $J_{\mathbf{f}}(\mathbf{x}_0)$, а скалярное умножение — на матрично-векторное произведение. Геометрически это означает, что вблизи точки $\mathbf{x}_0$ нелинейное отображение $\mathbf{f}$ ведёт себя как линейное преобразование, задаваемое якобианом.

[АНИМАЦИЯ: маленький квадратик во входной плоскости рядом с точкой $\mathbf{x}_0$. Отображение $\mathbf{f}$ переносит его в выходную плоскость — там он превращается в почти параллелограмм. Затем рядом показывается то же преобразование, выполненное матрицей $J$ — получается ровно такой же параллелограмм. Подпись: «вблизи точки $\mathbf{f}$ действует как умножение на $J$».]

Именно это свойство объясняет, почему якобиан так фундаментален. Каждое нелинейное отображение локально является линейным, и матрица Якоби — это и есть та локальная линейная аппроксимация.

#### Вычисление якобиана своими руками

Давайте посчитаем матрицу Якоби для конкретной функции. Возьмём $\mathbf{f}: \mathbb{R}^2 \to \mathbb{R}^2$:

$$
f_1(x, y) = x^2 + y, \qquad f_2(x, y) = \sin(xy)
$$

По определению,

$$
J_{\mathbf{f}}(x, y) = \begin{bmatrix} \dfrac{\partial f_1}{\partial x} & \dfrac{\partial f_1}{\partial y} \\ \dfrac{\partial f_2}{\partial x} & \dfrac{\partial f_2}{\partial y} \end{bmatrix} = \begin{bmatrix} 2x & 1 \\ y \cos(xy) & x \cos(xy) \end{bmatrix}
$$

В точке $(1, 2)$ получим:

$$
J_{\mathbf{f}}(1, 2) = \begin{bmatrix} 2 & 1 \\ 2\cos 2 & \cos 2 \end{bmatrix} \approx \begin{bmatrix} 2 & 1 \\ -0.832 & -0.416 \end{bmatrix}
$$

Теперь реализуем якобиан численно — поколоночно, через возмущение каждого входа:

```py
import numpy as np

def f(v):
    x, y = v
    return np.array([x**2 + y, np.sin(x*y)])

def jacobian(f, x, h=1e-6):
    n = len(x)
    fx = f(x)
    m = len(fx)
    J = np.zeros((m, n))
    for j in range(n):
        e = np.zeros(n); e[j] = h
        J[:, j] = (f(x + e) - f(x - e)) / (2*h)
    return J

x0 = np.array([1.0, 2.0])
print(jacobian(f, x0))
```

Вывод:

[[ 2.         1.       ]
 [-0.8322937 -0.4161468]]

Цифры в точности совпали с аналитическим вычислением. Обратите внимание на структуру кода: мы возмущаем по одному входу за раз и получаем целый столбец якобиана. Это и есть смысл столбца — он показывает, как все выходы реагируют на изменение одного входа.

Теперь сравним с готовой реализацией из PyTorch, которая использует автодифференцирование:

```py
import torch

def f_torch(v):
    x, y = v[0], v[1]
    return torch.stack([x**2 + y, torch.sin(x*y)])

x0 = torch.tensor([1.0, 2.0])
J = torch.autograd.functional.jacobian(f_torch, x0)
print(J)
```

Вывод:

tensor([[ 2.0000,  1.0000],
        [-0.8323, -0.4161]])

Результат идентичен. PyTorch внутри не считает разностные приближения — он применяет цепное правило к графу вычислений и получает якобиан точно, до машинной точности.

#### Цепное правило в матричной форме

Вот где матрица Якоби действительно показывает свою силу: в обобщении цепного правила. Для композиции вектор-функций $\mathbf{h} = \mathbf{f} \circ \mathbf{g}$ производная одной функции от другой становится произведением матриц.

{% capture notice %}
**Теорема (цепное правило для вектор-функций)**. Пусть $\mathbf{g}: \mathbb{R}^n \to \mathbb{R}^k$ дифференцируема в точке $\mathbf{x}$, а $\mathbf{f}: \mathbb{R}^k \to \mathbb{R}^m$ дифференцируема в точке $\mathbf{u} = \mathbf{g}(\mathbf{x})$. Тогда композиция $\mathbf{h} = \mathbf{f} \circ \mathbf{g}$ дифференцируема в $\mathbf{x}$, и

$$
J_{\mathbf{h}}(\mathbf{x}) = J_{\mathbf{f}}(\mathbf{g}(\mathbf{x})) \cdot J_{\mathbf{g}}(\mathbf{x})
$$

Это произведение матриц размеров $m \times k$ и $k \times n$, результат — матрица $m \times n$.
{% endcapture %}
{{ notice | markdownify }}

Это прямое обобщение одномерного цепного правила: вместо «перемножения скоростей» мы перемножаем матрицы локальных линейных приближений. И размеры идеально согласуются: количество столбцов одной матрицы (число выходов внутреннего отображения) совпадает с числом строк другой (число входов внешнего).

[АНИМАЦИЯ: цепочка из трёх облачков-пространств: $\mathbb{R}^n \to \mathbb{R}^k \to \mathbb{R}^m$. Над первой стрелкой подпись $\mathbf{g}$, над второй — $\mathbf{f}$. Под ними появляются матрицы $J_g$ (размера $k\times n$) и $J_f$ (размера $m \times k$). Они «склеиваются» в одну широкую матрицу $J_h = J_f J_g$ размера $m \times n$.]

Именно эта формула — математический фундамент backpropagation. Когда мы говорим «градиент течёт назад через сеть», под капотом происходит последовательное перемножение якобианов слоёв. Реализуем и проверим:

```py
# g: R^2 -> R^2,   f: R^2 -> R^2,   h = f o g
def g(v):
    x, y = v
    return np.array([x + y, x*y])

def f(u):
    a, b = u
    return np.array([a**2, a + b])

h = lambda v: f(g(v))

x0 = np.array([1.0, 2.0])
Jg = jacobian(g, x0)
Jf = jacobian(f, g(x0))
Jh_chain = Jf @ Jg
Jh_direct = jacobian(h, x0)

print("через цепное правило:\n", Jh_chain)
print("напрямую:\n", Jh_direct)
```

Вывод:

через цепное правило:
 [[ 6.  6.]
 [ 3.  2.]]
напрямую:
 [[ 6.  6.]
 [ 3.  2.]]

Матрицы идеально совпали. Произведение якобианов слоёв действительно равно якобиану всей композиции.
